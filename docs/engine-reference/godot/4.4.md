# Godot 4.4 引擎参考（《遮天》项目钉定版）

- 文档编号：ARCH-ENG-003
- 作者：engineering-lead（程基岩）
- 日期：2026-08-06
- 用途：项目内唯一引擎版本参考。所有 ADR / Story / 编码标准以本文钉定版本为准。

---

## 1. 版本锁定

- **钉定版本**：Godot **4.4.x stable**（GDScript 为主；**Web 导出仅支持 GDScript**）
- **许可**：MIT（免费、可商用、无 Runtime Fee）
- **版本治理**：项目锁 4.4 基线，升级（如 4.5/4.6）须走 ADR 评审；禁止跨 minor 版本漂移。
- **语言决策**（ADR-0001 延续）：
  - Web 端游戏逻辑：**统一 GDScript**（官方：Godot 4 项目用 C# 目前**无法导出 Web**）；
  - C# 仅限非 Web 工具/服务端（离线批处理、遥测处理等），不进游戏运行时；
  - 禁止"核心用 GDScript、部分用 C#"的双语言混排（心智负担与测试成本高）。

## 2. Web 导出要点（钉定口径）

| 项 | 口径 | 依据 |
|---|---|---|
| 导出模板 | 4.4 对应版本 Export Templates（Web） | — |
| 线程模型 | **单线程导出（默认，4.3+）** | 免 COOP/COEP 跨源隔离头；iOS/macOS 更稳；对静态托管/CDN 友好 |
| 多线程 | 不采用（MVP）；如未来启用需 COOP/COEP 头 + 跨源隔离部署 | 官方警告 SharedArrayBuffer 依赖 |
| 渲染 API | **WebGL2 为硬要求**；WebGPU 实验性（4.3+），不押注 | 官方文档 |
| 语言 | **GDScript only**（C# 不可导出 Web） | 官方文档 |
| 输出物 | index.html + godot.wasm + 资源 pck / 分块 | — |
| 体积预算 | 引擎壳 gzip 目标 ≤9MB / 硬门禁 12MB；首屏美术 ≤5MB；远程 Bundle ≤3MB | ARCH-ENG-002 §5 |
| 部署 | 任意静态托管 + CDN + 强缓存（哈希命名） | CI 方案 ARCH-ENG-005 |

## 3. 关键 API 备忘（面向《遮天》放置修仙 × 卡牌收集）

> 面向本作实际系统（放置收益 / 境界 / 养成 / 自动战斗 / 帝路异步竞技 / 存档 / 网络），按架构三层归类（见 ARCH-ENG-004）。

### 3.1 基础层
| 用途 | API/节点 | 备注 |
|---|---|---|
| 全局单例 | `Autoload`（project.godot 注册单例） | 白名单化，避免全局滥用；如 `GameState`、`SaveManager`、`NetManager` |
| 场景切换 | `get_tree().change_scene_to_file("res://...tscn")` | 4.x 用文件路径 |
| 资源加载 | `load()` / `ResourceLoader.load()` | 数据表/场景热加载 |
| 网络请求 | `HTTPRequest` 节点 / `HTTPClient` | 远程 Bundle、登录、遥测 |
| 数据解析 | `JSON.parse_string()`（4.x 静态） | 数值表 JSON 解析 |
| 存档 | `FileAccess` / `ConfigFile` / `user://` | 存档加密见 ADR（待立） |

### 3.2 核心层（纯逻辑，不依赖渲染，可单测）
| 用途 | 建议形态 | 备注 |
|---|---|---|
| 数值/经济引擎 | GDScript `RefCounted` 纯类（无 Node） | 可 headless 单测 |
| 战斗结算 | 回合制/半即时结算器（纯逻辑） | 布阵 + 自动战斗，可离线算 |
| 境界/养成 | 状态机 + 数值表驱动 | 五大境界框架（轮海→道宫→四极→化龙→仙台） |
| 离线收益 | 时间戳结算 | 上限 12h（概念文档） |
| 帝路竞技 | 镜像阵容结算（异步） | 无实时对抗 |

### 3.3 玩法层
| 用途 | API/节点 | 备注 |
|---|---|---|
| UI | `Control` 体系 + `Theme` | 卷轴/符箓/青铜铭文母题（美术圣经 §6.1） |
| 2D 场景 | `Node2D` / `TileMapLayer`（4.3+ 更名）/ `CanvasItem` | 荒古禁地新手区 |
| 动画 | `AnimationPlayer` / `Tween` | 战斗演出、突破演出（P1 情绪回报） |
| 卡面/立绘 | `TextureRect` + 图集 | 图集 ≤2048²（美术圣经 §8.1） |
| 粒子 | `CPUParticles2D` / `GPUParticles2D` | 共享粒子图集；移动端 ≤800 粒子（美术圣经 §7.3） |

## 4. 踩坑清单（已知，随实测持续补充）

1. **C# Web 导出不可用**：Godot 4 官方不支持；立项即统一 GDScript（最高优先级坑，防返工）。
2. **多线程导出部署陷阱**：需要 COOP/COEP + 跨源隔离，宿主页不能混第三方脚本/广告；MVP 一律单线程。
3. **WebGL2 缺失即白屏**：不支持 WebGL2 的旧浏览器直接不可用；需引导页提示升级浏览器。
4. **iOS Safari 内存沙盒**：低端 iOS 设备内存上限 ~1GB，长在线放置需对象池 + 定期回收；纹理用移动端压缩变体。
5. **Godot 4 API 与 3.x 不同**：`change_scene`→`change_scene_to_file`、`TileMap`→`TileMapLayer`（4.3+）等；团队若带 3.x 经验需培训。
6. **版本漂移**：4.x minor 间 API 有调整；锁 4.4，升级走 ADR。
7. **远程 .pck 加载回退**：需做加载失败回退 + 版本清单；本地占位资源兜底（美术圣经 §8.4 占位图口径）。
8. **字体体积**：全量中文字体极大；必须子集化（美术圣经 §6.3 ≤2MB），移动端系统字体回退。
