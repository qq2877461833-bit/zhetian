# EPIC-03 角色与养成（Characters & Growth）

- Epic ID：EPT-03
- 目标：落地角色数据模型、五维养成（等级/破境/升星/法宝/功法）、抽卡（GachaService，服务端权威）与账号境界上限约束。P2 支柱直接实现。
- 架构依据：ARCH-ENG-006 §3.4/§3.5/§3.9；GDD-002 全量；ADR-0002/0003/0004
- 依赖：EPT-02（境界/经济/离线）
- 验收总口径：角色表加载 → 养成 → 抽卡保底全链路服务端可结算、客户端只读展示

## Stories

### EPT-03-S01 角色数据表（character.json）
- REQ 锚点：REQ-002-3.1/3.2；REQ-002-6.1（稀有度色阶引用）
- ADR 指引：ADR-0004（引用完整性：class/rarity id 注册表）
- 验收标准（可测）：
  1. MVP 30 名角色表（原著 ≥70%、原创 4–6 名标支线）；
  2. 字段含 rarity/class/faction/base/growth/skills/origin；
  3. CI 校验：rarity 引用美术圣经 §5.4 六档、class 引用克制环三职业、skill id 注册表存在。
- 依赖：EPT-01-S07；EPT-02-S01

### EPT-03-S02 角色境界架构（独立境界 + 账号上限）
- REQ 锚点：REQ-002-3.3（每角色独立境界、非主角 ≤ 主角-1 大境）
- ADR 指引：ADR-0003
- 验收标准（可测）：
  1. `realm_ceiling` 返回非主角上限（主角-1 大境）；
  2. 达上限时突破被拒并返回"需提升主线境界"；
  3. 单测：主角/配角/边界（同境/差 1 境）三路径。
- 依赖：EPT-03-S01；EPT-02-S02

### EPT-03-S03 五维养成（CharacterService）
- REQ 锚点：REQ-002-3.2（等级/破境/升星/法宝/功法）
- ADR 指引：ADR-0003（服务端结算）；ADR-0004（数值表）
- 验收标准（可测）：
  1. level_up/promote_star/equip_artifact/train_skill 各维度可结算且资源消耗正确；
  2. 升星消耗碎片（同名/通用）；满星溢出转通用碎片（REQ-002-3.4）；
  3. 单测：每维度消耗与效果断言 + 资源不足拒绝。
- 依赖：EPT-03-S01/S02；EPT-02-S06

### EPT-03-S04 抽卡（GachaService：概率/保底/分段）
- REQ 锚点：REQ-002-3.1.2/7.3（概率公开、保底 60 地/90 天、卡池分段、源石碎片副产物）
- ADR 指引：ADR-0003（服务端 RNG + 保底持久化，防篡改点 #3）
- 验收标准（可测）：
  1. 概率表与 GDD-002 §3.1.2 一致；保底计数跨池不重置、UP 结束后继承常驻池；
  2. 卡池分段按账号境界开放（轮海期仅凡/灵/玄）；
  3. 服务端 RNG 可种子复现（同 seed 同结果），客户端无随机；
  4. 单测：保底必出断言（60 抽 ≥地品、90 抽 ≥天品）、分段拒绝、副产物。
- 依赖：EPT-03-S01；EPT-02-S06

### EPT-03-S05 养成与抽卡 UI（玩法层，只读展示）
- REQ 锚点：REQ-002-6.1/6.2/6.3（卡面/抽卡演出/养成入口）；美术圣经 §6
- ADR 指引：ADR-0003（客户端只读）
- 验收标准（可测）：
  1. 抽卡演出可跳过（P3）；出货 ≥地品才播全屏演出；
  2. 保底进度常驻展示；养成入口缺资源跳转"快速获取"；
  3. 场景冒烟：加载不崩溃，不持有状态。
- 依赖：EPT-03-S04；EPT-01-S02/S03
