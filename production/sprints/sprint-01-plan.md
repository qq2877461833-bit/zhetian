## 1. Sprint 1 目标

**垂直切片：让"闭关→突破→推关"核心循环在浏览器里真正可玩。**

一句话：用最小的真实代码 + 占位资产，验证 P1/P3 支柱的核心闭环（离线收益结算 → 境界突破演出 → 主线推关验证），并跑通基础框架（启动/存档/CI）。

## 2. 范围（Scope）

### 纳入（In）
- **EPT-01 基础框架（S01-S07 全量）**：Godot 4.4 脚手架、Bootstrapper 加载阶段机、ResourceManager、NetManager、SaveManager、TimeService/Telemetry、CI 体积门禁
- **EPT-02 核心闭环子集**：S01 境界成本表加载、S02 离线结算、S03 突破流程（小段即时 + 大境界等待模拟）、S04 修炼位最小实现（1 位）+ 资源栏
- **核心层单测**：13 条（RealmEngine 成本公式 ×6 / IdleIncomeEngine 离线结算 ×7）跑通
- **占位资产**：标题场景 + 荒古禁地新手区低模 + 基础 UI（引用 MVP 资产规格 P0 清单）

### 排除（Out）
- 角色抽卡、帝路竞技、副本完整掉落（EPIC-03/05/06 全量）——Sprint 2+
- 战斗演出完整特效（用占位粒子）
- 远程 Bundle 流式（阶段 2 机制验证单独 Story）

## 4. 验收标准（Sprint 1 完成定义 · DoD）

1. CI 绿：Lint + Schema 校验 + 13 条单测 + Web 导出 + 体积门禁（首屏 <5MB / 引擎壳 ≤12MB）；
2. 垂直切片可玩：浏览器打开 → 加载（阶段 0→1）→ 收菜（离线收益结算演出）→ 突破 1 次（紫气演出）→ 推 1-3 关主线（自动战斗占位）→ 关游戏重开，离线收益正确累计；
3. 支柱校验：P1（突破埋点 last_breakthrough_ts 上报）/ P3（单会话 5 分钟可完成闭环）；
4. 实测清单执行：ARCH-ENG-002 §6 六项至少完成"空包体积 + 单线程部署头"两项实测，回填报告。

## 5. 已知阻塞与依赖（需项目方决策）

**P0 阻塞：Godot 实测环境缺失**——本机无 Godot 4.4、沙箱无外网。工程线已输出实测条件清单 6 项（Godot 4.4 + Web 导出模板 + 压缩工具 + 浏览器矩阵 + 网络 + shell 输出）。单测骨架已就位但未跑通，EPIC-01 S01（脚手架）无法实施。

| 选项 | 说明 |
|------|------|
| A. 提供含 Godot 的环境 | 用户侧安装 Godot 4.4 或提供可远程执行的环境 → 实测与单测立即解锁 |
| B. 接受"待实测"延期 | Sprint 1 先做不依赖 Godot 的部分（Story 拆分/Schema/CI 配置/数值表 JSON），实测项延后到环境就绪 |
| C. 工程线输出安装指引 | 工程线产出《Godot 4.4 环境安装与验证清单》（含下载源/配置/首测命令），用户按指引执行后回填 |

**已拍板（2026-08-06）**：**提供远程环境**（用户提供可远程执行 Godot 的环境接入信息，工程线接入后执行实测清单 + 跑 13 条单测；接入前先推进不依赖环境的部分）。
