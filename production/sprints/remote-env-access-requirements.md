# 远程环境接入需求清单（供项目方提供环境）

- 文档编号：SPR-01-ENV-REQ
- 作者：engineering-lead（程基岩）
- 日期：2026-08-06
- 目的：Sprint 1 实测环境方案 = 用户提供远程环境。本清单列明**接入所需的具体信息与权限**，供主理人转交项目方准备。
- 对应：ARCH-ENG-002 §6.2 实测条件清单（6 项）；Sprint 1 验收 DoD #4

---

## 0. 接入后立即执行的优先级

1. **空包体积实测**（ARCH-ENG-002 §2：单线程导出 gzip/Brotli 压测）→ 决定预算口径是否沿用/上修；
2. **13 条单测跑通**（tests/unit，GUT）→ 核心层闭环验证；
3. **EPT-01-S01 脚手架验证**（godot --version + 空项目 Web 导出）。

---

## 1. 连接方式（必填其一）

| # | 项 | 需要项目方提供 | 说明 |
|---|---|---|---|
| 1.1 | 远程执行方式 | □ SSH 主机（host:port / 账号 / 密钥或口令）<br>□ 远程桌面（RDP/AnyDesk 等）<br>□ 用户本地执行 + 回传输出（推荐最少干预） | 工程线需能运行 shell 命令并取回输出/产物 |
| 1.2 | 工作目录 | 可写目录路径（构建、缓存、导出产物） | 需要 `mkdir`/写文件权限 |
| 1.3 | 回传通道 | 命令输出如何回传（日志/构建产物） | 支持文件上传或共享目录更佳 |

## 2. Godot 环境

| # | 项 | 需要确认/提供 | 说明 |
|---|---|---|---|
| 2.1 | Godot 版本 | **4.4.x stable**（标准版，非 .NET 版） | Web 导出仅 GDScript；.NET 版不能导出 Web（ARCH-ENG-003 §2） |
| 2.2 | 可执行方式 | `godot` 或 `godot4` 在 PATH；或提供可执行文件路径 | 需支持 `--headless` |
| 2.3 | Web Export Templates | 已安装与 4.4.x 匹配的导出模板 | 官网下载一次性；用于 `--export-release` |
| 2.4 | 验证命令 | 接入后首测：`godot --version` | 预期输出 `4.4.x.stable` |

## 3. 工具与权限

| # | 项 | 需要提供 | 说明 |
|---|---|---|---|
| 3.1 | shell 访问 | 可运行：`godot --headless`、`python3`、`curl`/`wget`、`gzip`/`brotli` | 体积压测与 Schema 校验用 |
| 3.2 | 网络 | 下载 Godot/导出模板；验证 CDN 缓存头 | 若受限请说明白名单/代理 |
| 3.3 | 静态服务器 | 可起本地静态服务器（python -m http.server 或类似） | 单线程导出部署头验证 + 远程 .pck 机制验证 |

## 4. 浏览器/真机矩阵（Sprint 1 最小集）

| # | 目标 | 需要提供 |
|---|---|---|
| 4.1 | Chrome / Edge（桌面） | 至少 1 种，用于空包部署头验证 |
| 4.2 | iOS Safari / Android Chrome（移动） | 至少 1 种（真机优先，模拟器可），用于 WebGL2/首场景 Profile 初验 |

## 5. 安全与时限

| # | 项 | 建议 |
|---|---|---|
| 5.1 | 会话时长 | 单次接入 ≥ 1h（含模板下载/构建/压测） |
| 5.2 | 权限边界 | 仅需构建/测试目录写权限；无系统级安装要求（除 Godot 本体） |
| 5.3 | 凭据 | SSH 密钥或一次性口令，用完即弃 |
