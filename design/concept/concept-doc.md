# 《遮天》游戏概念文档（Concept Doc）

- 文档状态：V1.0 草案（Phase 1 概念孵化）
- 主理人：游承峰
- 作者：文策渊（设计策略）
- 协作方：art-director（视觉锚点将并入美术圣经）、engineering-lead（可实现性边界）
- 目标平台：Web / 多端（浏览器优先）【硬约束】
- 评审强度：Full

---

## 0. 一句话定位

**一款"逆天改命、片刻亦可修仙"的放置修仙 × 卡牌收集 Web 游戏，以《遮天》原著群像为角色池，让玩家在碎片时间里重走北斗星域的帝路。**

---

## 1. 设计支柱（Design Pillars）

每条支柱是可验证的主张，任何系统取舍都应回到支柱校验，偏离即为支柱漂移。

| # | 支柱 | 一句可验证的主张 |
|---|------|------------------|
| P1 | **逆天争锋** | 玩家每 24 小时内应至少经历 1 次"积累→瓶颈→突破"的成长峰谷，突破瞬间是核心情绪回报；若玩家 48 小时无突破体验，判定支柱失守。 |
| P2 | **帝路群像** | 角色池以原著人物为核心资产，收集/培养/布阵构成核心策略层；首月可收集角色 ≥ 30 名，其中原著角色占比 ≥ 70%。 |
| P3 | **片刻亦修仙** | 单次会话 1–10 分钟均能产生有效进展（收菜、一键突破、布阵调整）；离线收益上限设计为"即开即玩即有获得感"，不惩罚回归。 |
| P4 | **忠于遮天** | 境界体系（轮海→道宫→四极→化龙→仙台）、核心人物人设、开篇事件（九龙拉棺、荒古禁地）必须忠于原著；可原创扩展仅限支线与事件化玩法，不魔改主线与体系框架。 |

## 2. MDA 分析

### 2.1 机制（Mechanics）

| 机制 | 说明 |
|------|------|
| 资源生产 | 源石/灵石等基础资源随时间产出，配合"修炼位"加速；挂机离线照常结算。 |
| 境界突破 | 轮海→道宫→四极→化龙→仙台五大境界，每大境含小段位；突破消耗资源+时间+关卡验证，是长线核心成长轴。 |
| 角色收集与养成 | 抽卡/剧情/活动获取角色；培养维度：等级、境界、装备（法宝）、突破（升星）、功法。 |
| 布阵与自动战斗 | 上场 4–6 名角色，回合制/半即时自动战斗，玩家决策在"布阵+功法搭配+技能时机（可手动）"。 |
| 副本与挑战 | 主线关卡（名场面再现）、资源副本、试炼塔、异步竞技（帝路）。 |
| 离线收益 | 按时间累积资源与经验，上限 12 小时；回归时有"结算仪式"反馈。 |

### 2.2 动态（Dynamics）

- **积累→瓶颈→突破**：资源产出有边际收益递减，突破需要"资源+时机+关卡验证"，形成节奏峰谷；P1 的验证锚点。
- **收集驱动**：图鉴补全、阵营羁绊、原著情怀激励持续收集；抽卡概率与保底决定付费/免费平衡。
- **阵容克制循环**：角色分属性/阵营（如体质、神通、兵器流派），形成克制闭环，避免单一主导策略（见 §9 红线）。
- **回流满足**：离线收益+回归奖励让玩家"离开越久回来越有收获"，但设上限防止资源通胀。

### 2.3 美学（Aesthetics）

- **成长/成就（P1）**：境界突破的演出、数字飞涨、称号加冕。
- **收藏/发现（P2）**：角色图鉴、原著名场面档案、隐秘支线。
- **策略掌控**：布阵克制、预判战斗结果。
- **情怀共鸣（P4）**：九龙拉棺开篇、荒古禁地探索、熟悉台词与招式名。
- **掌控命运的叙事**：以"逆天改命"为主线情绪的碎片叙事。

## 3. 动词优先法（Verb-First）

### 3.1 核心动词循环

```
修炼(积累) → 突破(提升) → 结伴(收集) → 布阵(策略) → 争锋(验证) → 论道(叙事/图鉴) → 回到修炼
```

每局（单次会话）最小闭环：

```
打开 → 收菜（领取离线收益） → 一键突破/升级 → 推进 1–3 关主线 → 布阵微调 → 关闭
（5–10 分钟）
```

长线闭环（周/月）：

```
修炼积攒 → 冲击大境界 → 解锁新地图/名场面 → 收集新角色 → 阵容重构 → 帝路排行提升 → 更高目标
```

### 3.2 核心体验节奏

| 节奏层 | 周期 | 内容 | 情绪 |
|--------|------|------|------|
| 微循环 | 1–10 分钟 | 收菜、突破小段、推 1–3 关 | 即时满足 |
| 中循环 | 30–120 分钟 | 副本推进、试炼塔、收集规划 | 目标感 |
| 大循环 | 1–7 天 | 大境界突破、新角色、帝路段位 | 成长史诗 |
| 超长循环 | 月级 | 新章节、新阵营、赛季活动 | 长期留存 |

## 4. 玩法类型建议与候选形态

### 4.1 主推：放置修仙 × 卡牌收集（Idle Cultivation × Card Collection）

- **形态**：挂机资源生产 + 角色收集养成 + 自动战斗布阵 + 异步竞技（帝路）。
- **理由**：
  1. Web 硬约束下开发成本与性能风险最低（无实时动作/物理/大规模同屏），浏览器即开即玩，移动端网页同样流畅。
  2. 放置挂机与"闭关修炼"母题天然契合，"离线收益"= "闭关出关"，叙事与机制自洽。
  3. 《遮天》海量角色（叶凡、庞博、姬紫月、黑皇、段德、狠人、无始、虚空……）天然支撑收集玩法，IP 资产复用度最高。
  4. 商业模式成熟、验证充分，适合工作室首款 Web 产品控制风险。
- **风险与对策**：放置品类易显"数值空虚" → 用名场面剧情+图鉴+帝路竞技补足内容厚度；抽卡付费敏感 → 保底+原著情怀事件化。

### 4.2 备选 A：2D 横版动作（类恶魔城/横版清版）

- **形态**：2D 横版探索 + 动作战斗，叶凡等角色操作，名场面为关卡。
- **优势**：表现力强、IP 情怀浓度高、单人叙事完整。
- **劣势**：Web/多端动作手感与性能优化成本高；开发周期长，MVP 难闭合；触屏操作适配风险大。
- **结论**：IP 热度验证后的二期形态候选，不作首发。

### 4.3 备选 B：俯视角 ARPG（类暗黑/原神式）

- **形态**：俯视角实时战斗 + 开放地图探索。
- **优势**：品类天花板高、商业化空间大。
- **劣势**：Web 性能瓶颈明显（同屏/粒子/大地图流送）；开发成本与周期显著超出当前团队节奏；与"碎片时间"支柱冲突。
- **结论**：最不适合当前硬约束，仅作远期愿景参考。

> **决策建议**：以主推形态立项；工程线按此选型（轻量引擎/框架即可满足），美术线按"2D 卡面 + 场景 + 战斗演出"出资产规范。

## 5. 范围分层（Scope Layering）

### 5.1 MVP（首发验证，务必落地）

- 核心放置循环：资源生产 + 离线收益 + 修炼位。
- 境界系统：轮海→道宫（前两大境完整），四极以降作为后续内容预留框架。
- 角色：首版 20–30 名（原著为主），抽卡 + 剧情赠送双获取；养成含等级/突破/基础法宝。
- 战斗：布阵 + 自动战斗（可手动放关键技能），5–8 章主线名场面关卡。
- 帝路竞技：异步 PvP（镜像阵容对打 + 段位），轻量竞争闭环。
- 经济：源石/灵石双币 + 突破材料；保底机制。
- 叙事：九龙拉棺开场演出 + 荒古禁地新手区 + 名场面档案系统。

### 5.2 核心层（上线后 1–2 个季度）

- 完整五大境界 + 角色专属功法/法宝系统。
- 更多阵营与羁绊、图鉴补全、试炼塔、资源副本轮换。
- 宗门/势力系统（原著阵营倾向，非重社交）、限时活动（黑暗动乱、成仙路预兆等事件化玩法）。
- 赛季制帝路 + 排行奖励。

### 5.3 扩展层（远期，视数据与资源）

- 实时 PvP / 组队副本、开放探索玩法（北斗七大陆漫游）。
- 多线剧情（if 线/补全支线）、长篇赛季剧情。
- 若二期转型，可评估 2D 横版动作子模式。

### 5.4 明确不做（MVP 阶段红线）

- 开放世界 / 大地图自由探索。
- 实时动作战斗、硬核操作门槛。
- 重社交（公会实时协作、语音、交易）。
- 实时 PvP（仅异步）。
- 任何与 Web 浏览器优先冲突的高性能需求（大场景流送、重度 3D）。

## 6. 视觉锚点（供美术线对齐）

> 以下为意象级锚点，具体色值/形制由 art-director 在美术圣经中落实。

1. **九龙拉棺（开场图腾）**：九条龙尸拖青铜巨棺穿越星空裂隙，史诗、肃穆、悲壮——开篇即封神的情绪锚点，用于 Logo 与开场演出。
2. **荒古禁地（新手区）**：苍凉深邃、古木参天、雾霭锁山的禁区意象；"不可久留"的压迫感与神秘感，确立世界观基调。
3. **源石与紫气（资源与稀有度）**：晶莹剔透的源石（内蕴神华）、紫气东来的帝气光效——高稀有度/高境界的视觉语言，贯穿 UI 与卡面。
4. **北斗星域七大陆（地图色彩体系）**：东荒青绿、西漠金黄、南岭赤红、北原雪白、中州紫金……以色彩区分地域，作为地图/关卡/活动的主视觉骨架。
5. **帝路与仙光（成长峰值演出）**：金色帝光、混沌雾霭、登临绝顶的剪影——境界突破、帝路晋升的专属演出层级，与日常资源反馈拉开档次。

## 7. 目标玩家画像与 Bartle 类型

### 7.1 核心画像

- **年龄/性别**：25–40 岁，男性为主。
- **背景**：读过《遮天》原著或有修仙网文阅读史；对"九龙拉棺、帝路争锋"有情怀记忆。
- **习惯**：碎片时间玩家（通勤、午休、睡前），熟悉放置/卡牌品类，有收集与养成习惯，付费意愿中等。
- **设备**：桌面浏览器 + 手机浏览器切换，倾向"不下载即玩"。

### 7.2 次级画像

- 泛修仙题材爱好者（未读原著，因题材入坑）。
- 放置类玩家（被低门槛与成长反馈吸引）。
- 原著粉/剧粉（因 IP 入坑，对名场面还原敏感，对魔改零容忍）。

### 7.3 Bartle 类型倾向（设计权重）

| 类型 | 权重 | 对应设计 |
|------|------|----------|
| Achiever（成就者） | 45% | 境界突破、称号、帝路段位、图鉴完成度 |
| Collector（收集者） | 30% | 角色卡池、法宝图鉴、名场面档案 |
| Explorer（探索者） | 15% | 支线事件、世界观档案、隐藏彩蛋 |
| Killer（竞争者） | 10% | 异步竞技/排行（不设实时对抗） |

> 结论：**Achiever + Collector 主导**；Killer 以异步方式满足，避免实时对抗带来的投入门槛。

## 8. 与《遮天》IP 的叙事切入点

### 8.1 必须保留（红线，不可魔改）

- **开篇事件**：九龙拉棺（地球→北斗），作为开场演出与主线起点。
- **核心场景**：荒古禁地（新手区）、北斗星域七大陆（地图骨架）。
- **境界体系**：轮海→道宫→四极→化龙→仙台，框架不可改（可简化数值，不可改结构）。
- **核心人物人设**：叶凡（坚毅求活）、庞博（义气）、姬紫月（聪慧）、黑皇（贪财大黑狗）、段德（无良道士）、狠人/无始/虚空等大帝位格。
- **主题基调**：逆天改命、与天争锋、帝路争锋。

### 8.2 可原创扩展（明确边界）

- **支线剧情**：非核心人物的独立小传、事件化副本（如"黑暗动乱"活动剧本），不触碰主线因果。
- **事件玩法**：以原著事件为背景的活动（如成仙路异动、禁区异象），结果可演绎但背景须尊重原著设定。
- **角色关系补全**：原著未展开的关系可在档案/支线中补全，不得与已有人设冲突。

### 8.3 建议取舍

- **前期叙事策略**：MVP 聚焦"名场面再现"（九龙拉棺→荒古禁地→初入北斗），用演出与档案系统承载情怀；不做大段原创主线。
- **剧透控制**：后期剧情（成仙路终局、狠人因果）作为长期扩展钩子，不在首发展开，保留内容纵深。
- **IP 敏感点**：不魔改境界体系、不改变核心人物命运结局、不虚构"超越大帝"的新位格；若需新增原创角色，须为支线/活动限定，不进核心主线。

## 9. 设计红线（评审自查）

- **杜绝主导策略**：阵容克制须成闭环（任意单一阵容不可通吃所有内容）；功法/法宝不得出现唯一最优解。
- **经济平衡**：离线收益上限防通胀；抽卡保底公开；付费不得直接卖"境界突破"（只可加速资源，不卖成长本身）。
- **认知过载**：单会话主操作 ≤ 3 个（收菜/突破/推关），系统逐层解锁，新手期 10 分钟内只呈现一个核心动作。
- **支柱漂移**：任何系统上线前过 P1–P4 校验；若与"片刻亦修仙"冲突（如强制在线时长），一律修正。
