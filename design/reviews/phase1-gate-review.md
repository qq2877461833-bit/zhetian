## 2. 核心结论摘要

- **定位**：一款"逆天改命、片刻亦可修仙"的放置修仙 × 卡牌收集 Web 游戏，以《遮天》原著群像为角色池。
- **四大支柱**：P1 逆天争锋（24h 一峰谷）、P2 帝路群像（首月 ≥30 角色）、P3 片刻亦修仙（1-10 分钟有进展）、P4 忠于遮天（境界/人设/开篇不可魔改）。
- **主推形态**：放置修仙 × 卡牌收集（挂机 + 收集 + 自动战斗布阵 + 异步帝路竞技）。
- **引擎**：主选 Godot 4.x（GDScript），备选 Cocos Creator 3.8 LTS（条件触发）。
- **审美**：「荒古苍凉为骨，仙道星辉为魂」，东方荒古写实幻想。

## 5. 已知风险与缓解

| 风险 | 等级 | 缓解 |
|------|------|------|
| 放置品类数值空虚 | 高 | 名场面剧情 + 图鉴 + 帝路竞技补厚度（策划 §4.1 已对策） |
| 抽卡付费敏感 | 高 | 保底公开、不卖成长本身只加速资源（策划 §9 红线） |
| Godot Web 不支持 C# | 中 | Web 端统一 GDScript，C# 仅限工具链（ADR-0001 R4） |
| iOS Safari WASM/内存限制 | 中 | Compatibility 管线 + 纹理压缩 + context lost 自动恢复（ADR-0001 R2） |
| IP 授权边界 | 中 | 概念期仅作红线管理；**商业发行前须完成《遮天》IP 授权确认**（发布阶段风险项，提前登记） |
| 长线资产膨胀 | 中 | 数据驱动 + 分包/远程 Bundle + CI 体积门禁（ADR-0001 R3） |
