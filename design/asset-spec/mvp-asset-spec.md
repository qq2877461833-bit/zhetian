## 2. 首屏资产清单（阶段 1 ≤5MB 对账）

> 依据美术圣经 §8.4 分阶段预算模型 + ARCH-ENG-002 §5.2：阶段 1 美术增量配额 **≤5MB（硬门禁 6MB）**。以下为 P0 首包资产逐项对账（估算基于 WebP 压缩经验值，最终以打包实测校准）。

| 资产 | 规格 | 估算体积 | 说明 |
|---|---|---|---|
| 字体子集（Noto Serif SC 标题 + Noto Sans SC 正文） | 子集化 WOFF2 | ≤2.0MB | 硬配额，按剧情文本预生成子集 |
| UI 核心（卷轴/符箓/铭文 + 图标 24 + 稀有度边框 6） | 图集 `ui_atlas_panel` + `ui_atlas_icon` | ≤1.2MB | 两图集合计 ≤2048²×2 |
| 标题场景（九龙拉棺背景 + Logo 分层） | 2048² WebP | ≤0.4MB | 首屏加载即见 |
| 荒古禁地新手区（TileMap + 背景低模档） | 2048² + TileSet | ≤0.9MB | 新手区完整可玩 |
| 主角/核心角色卡面精简（叶凡 + 剧情赠送 1–2 名） | 512×640 + 头像 | ≤0.5MB | 进首包保证开局收集反馈 |
| 特效：荒古封印 + 鎏金描边 + 紫气精简 | 粒子图集共享 2–3 张 | ≤0.3MB | 新手区 + 首次突破演出可用 |
| **合计** | — | **≤5.3MB（目标 ≤5MB，微超需压缩档）** | 若超限：立绘降档、UI 图集二次去重、字体子集再裁剪 |

> **对账结论**：首包清单可收敛到 5MB 量级，但处于边缘；**风险控制动作**：① 字体子集是最大单项，按首屏剧情文本优先，后续剧情字体随 Bundle 加载；② UI 图集去重（按钮共用九宫格切片）；③ 主角立绘首包只进卡面精简档，高清立绘走 P1 Bundle。若硬门禁 6MB 仍紧张，与 engineering-lead 对齐后按 §2 表格内降级顺序裁剪。

## 3. 角色立绘规格（六档稀有度卡面）

- **立绘**：1536×2048（3:4），全身或半身由剧情需要决定；五官/服饰细节对齐美术圣经 §4 角色视觉方向（材质阶梯：凡尘粗布 → 修士丝绸 → 仙道云锦 → 禁忌哑光）。
- **卡面**：512×640，含立绘缩略 + 稀有度边框（§5.4 六档）+ 境界/星级/阵营标识位；破境后卡面动态升级（边框流光 + 背景升级，GDD-002 §6.1）。
- **剪影占位**：未收集角色图鉴显示「剪影 + 神秘光」（GDD-002 §6.1），剪影保留角色可辨识轮廓，激发收集欲；剪影不做稀有度边框（未知稀有度，避免剧透）。
- **演出资产**：
  - 天品/帝品出货 = 全屏紫气东来（§7.1 仙道法术类，星紫+鎏金渐变 + 紫气点缀）+ 角色登场 + 名台词（GDD-002 §6.2）；「减少动效」开启时演出转静态高亮（可访问性 §2.4）。
  - 帝品边框含铭文（青铜铭刻感），天品含流光，严格按 §5.4 不混级。
- **AI 生成提示词**（统一模板见 §1.1 引用框，角色替换 + 稀有度色 + 姿态描述）。

## 4. 场景规格（TileMap / Streaming / 七大陆扩展位）

### 4.1 战斗场景（引用 GDD-003 6 章）
- **TileMap 密度**：网格 128²，每场景 TileSet ≤ 64 个 tile（含地形/边缘/装饰复用）；地面纹理 512² 平铺 + 1 张 2048² 背景层（近景/中景/远景按美术圣经 §5.2 大气透视三级）。
- **分包规划**：每章场景一个远程 Bundle（≤3MB，引用 §8.4 阶段 2）；第 1–2 章（九龙拉棺→荒古禁地）P1 第一批，第 3–6 章 P2。
- **名场面节点**（GDD-003 §4.1）：九龙拉棺开场演出（P0 标题场景复用）、荒古禁地死寂（P0 新手区）、初入北斗星域过场（第 10 关，P1 演出背景）、太玄门考核、姬家初见（P2）。

### 4.2 界面/主城场景
- 主界面背景（`scene_main`）为「修仙洞府 + 云海」静态层 + 修炼位 UI 叠加；不做可漫游主城（MVP 2D 主导，符合概念文档红线）。
- 修炼位（GDD-001 多修炼位）用界面卡片表现，不建 3D 场景。

### 4.3 副本场景（引用 GDD-004）
- 资源副本 5 类：**复用章节场景变体**（换色调层 + 物件置换，成本最优）；源石秘境用「星紫 + 矿晶」专属变体（呼应 §5.4 源石视觉）。
- 试炼塔：复用战斗场景 + 塔层氛围叠加（每 10 层换色档）。

### 4.4 七大陆扩展位（引用美术圣经 §5.1.1）
- 东荒 = 默认地图色（青铜绿，已含新手区/章节 1–3）。
- 西漠/南岭/北原/中州为 P2 预留 Bundle；派生规则：从既有色板取主色 + 1 氛围强调色，禁止色板外高饱和新色；大陆间以雾霭/山脊过渡。

## 5. UI 规格（三母题资源清单）

- **卷轴**（面板）：9 切片（四角 64² + 四边 + 中心），展开 512×640；深色底墨青 `#1C2A26` @75%（可访问性文本背景）。
- **符箓**（按钮）：9 切片 4 态（常态/按下/置灰/高亮）；高亮 = 鎏金描边 + 脉动（可突破状态，GDD-001 §6.3）；置灰 = 降饱和 + 缺口文案。
- **铭文**（进度/加载）：铭文刻录动效 + 进度条九宫格；加载文案走字体层。
- **图标三档**：64（列表/小状态）/128（按钮/技能）/256（卡面/大图标）；统一 2px 描边、圆角 2px（美术圣经 §6.2）；稀有度着色引用 §5.4（含图标形态层级双通道，色盲安全）。
- **字体**：Noto Serif SC（标题 Bold 28–48px）+ Noto Sans SC（正文 14–18px）子集化 WOFF2，总 ≤2MB；数字用 Tabular（防跳动，GDD-001 §6.4）。

## 7. 与可访问性规格的对齐注记（资源侧实施点）

> 引用可访问性规格 v1.0；美术资源生产时必须满足，QA 按 §5 自查清单验收。

| 可访问性条款 | 资源侧实施点 |
|---|---|
| 正文对比度 ≥4.5:1 / UI 内 ≥7:1 | UI 图集背景统一墨青 `#1C2A26` @75% 半透明底；月白文字；禁用灰底灰字 |
| 色盲安全（不单靠颜色） | 稀有度=色值+图标形态双通道（§5.4）；阵营/状态图标+文字；**卡面边框光效不能只靠颜色表达稀有度** |
| 色盲滤镜三型预设 | 滤镜作用于渲染层，不影响图集资产本身；资产生产阶段用色盲模拟校验关键信息可辨 |
| 字号 ≥14px / 200% 缩放 | 字体子集含 14–48px 关键字号位图或可变字重；布局相对单位，不写死像素 |
| 减少动效开关 | 紫气演出/抽卡演出/突破演出在「减少动效」下转静态高亮；动效资产须提供静态帧 |
| 动效频闪 ≤3Hz | 演出资产频闪控制；铭文/警示用静态高亮替代强制闪烁 |
| 文本背景 | 字幕/悬浮文本容器统一带半透明底（UI 图集预设） |
