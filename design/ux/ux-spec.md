## 1. UX 设计原则

承接概念文档 §9 设计红线，UX 规格的顶层原则（可验证）：

| # | 原则 | 可验证主张 | 来源 |
|---|---|---|---|
| U1 | **认知过载控制** | 任意时刻主界面可交互主操作 ≤ 3 个；新系统逐层解锁，不一次性铺开 | 概念文档 §9「单会话主操作 ≤3 个」 |
| U2 | **片刻亦修仙（碎片友好）** | 单会话 1–10 分钟必有有效进展；所有长流程可中断/可跳过/可挂机 | P3 支柱 / GDD-003 §6.2 |
| U3 | **单一核心动作原则** | 新手 10 分钟内只呈现一个核心动作（收菜→突破），30 分钟内逐步引入 3 个 | GDD-001 §4.3 / GDD-002 §4.3 |
| U4 | **可访问性是默认值** | 所有界面交付前按可访问性规格 Standard 验收；无「仅靠颜色」信息 | accessibility-spec §2 |
| U5 | **反馈分层** | 日常反馈（数字/飘字）与峰值反馈（突破/出货演出）层级分明，峰值不可滥用 | 美术圣经 §7 / GDD-001 §6 |

## 2. 信息架构（IA）

### 2.1 主界面导航图（入口层级）

```
主界面（HUD）
├── 顶层常驻（一屏可见）
│   ├── 顶部资源栏：灵石 / 源石（稀有度着色 §5.4，源石星紫 #4A3E6E）
│   ├── 玩家信息：境界称号 / 等级 / 段位（帝路）
│   └── 设置入口（齿轮：可访问性/音效/减少动效/重映射）
├── 主操作区（U1：核心三动作）
│   ├── 【闭关/出关】主按钮（焦点位，一屏可见）
│   ├── 【突破】按钮（可突破时高亮：亮边+脉动+文字，三通道）
│   └── 【推关】按钮（主线下一关 / 扫荡入口）
└── 次级入口（功能导航，层级 2）
    ├── 修炼位（多角色管理，GDD-001 §3.2.4）
    ├── 秘境（副本 + 试炼塔，GDD-004）
    ├── 帝路（异步 PvP，GDD-005）
    ├── 图鉴（角色/名场面/世界观档案，P2 收集）
    ├── 抽卡（卡池入口，GDD-002 §3.1）
    └── 背包 / 角色（养成详情）
```

- **层级规则**：主操作区永远 ≤3 个主按钮（U1）；次级入口用图标+文字双通道（不单靠图标颜色，accessibility-spec §2.4）。
- **动线**：一屏 = 收菜（出关）→ 突破 → 推关，无需跳转即完成日常最小闭环（U2）。

### 2.2 全局导航规则

- 返回路径：所有二级页提供「返回主界面」主按钮（单一输入可完成主流程，accessibility-spec INP-1）。
- 页面栈：移动端底部 tab + 桌面端侧栏双形态，同一信息架构，不做两套逻辑（跨端一致）。
- 通知/红点：红点必须伴随文字角标（数量/文案），不单靠颜色（COL-1）。

## 3. 核心流程线框（文字级）

> 每条流程标注可访问性引用点（编号见 accessibility-spec §5 自查清单）。

### 3.1 新手 30 分钟流程（合并 GDD-001 §4.3 + GDD-002 §4.3）

```
0:00  九龙拉棺开场演出（可跳过；全字幕 AUD-1/C3；减少动效 MOT-2）
0:03  进入荒古禁地新手区 → 教学「闭关→出关」（收菜）
      【引导遮罩】高亮 闭关按钮 + 文字提示（COL-1 双通道）
0:06  第一次突破（轮海·苦海→命泉）→ 紫气东来演出（MOT-2 可关闭）
      → 称号加冕（文字+音效+视觉三通道 AUD-2）
0:10  推第 1 关主线（自动战斗默认开；跳过演出 INP-3 长按/点击）
0:13  教学「收菜→突破→推关」三动作闭环结束（U3 完成单一核心动作）
      【提示】「更多系统将随境界解锁」（认知过载控制 U1）
0:15  主线第 2 关 → 首次剧情角色赠送（庞博）→ 教学「角色可上阵」（P2）
0:20  首次十连（系统赠送券）→ 抽卡教学（保底提示透明化 G4）
0:25  教学「秘境入口」→ 首次灵石副本（1 次）→ 扫荡概念展示
0:30  自由游玩；引导提示「每日任务已开启」（全部任务 10 分钟内可完成）
```

- 可访问性引用：AUD-1（字幕）、AUD-2（三通道）、COL-1（双通道）、INP-1（单一输入）、INP-3（长按替代连点）、MOT-2（减少动效）。
- 原则：0–10 分钟只教一个核心动作（U3）；10–30 分钟渐进引入 2–3 个次级系统（U1）。

### 3.2 每日 10 分钟清日常流（P3 核心验证）

```
打开（≤10s 加载）→ 出关结算（领取离线收益，卷轴动效+鎏金数字 TYP-4）
→ 突破（若可突破；否则一键升级）→ 推关/扫荡主线（3 星已通自动扫荡）
→ 秘境清日常（灵石/经验/法宝/功法/源石 各 1 次，扫荡秒过）
→ 帝路挑战（5 次，全自动）→ 抽卡（若有券，可跳过演出）
→ 领每日任务奖励（红点+文字角标）→ 闭关（退出）
总时长：5–10 分钟
```

- 可访问性引用：TYP-4（文本背景）、INP-3（长按/一键）、MOT-2（减少动效）、AUD-2（三通道反馈）。
- 原则：每条日常 ≤60s 操作；全程 0 手动战斗（U2）；任务项全部可在此流程内完成。

### 3.3 大境界突破流（含等待 UI，GDD-001 §3.1/§6.2.1）

```
突破条件满足（资源+关卡验证通过）
→ 点击【突破】→ 确认弹窗（显示消耗资源/等待时长/加速选项）
→ 启动大境界突破（轮海→道宫 1h / 后续 2h）
→ 主界面出现「破境中」计时条（铭文刻录动效，MOT-2 可降级）
→ 等待期间可自由离线（P3 保护条款：计时走服务器时间戳，离线不重置）
→ 回归：若等待已结束 → 出关结算页同屏呈现「破境完成」+「离线收益」
→ 全屏紫气东来演出（§5.4 帝品/天品层级，MOT-2 可关）→ 境界称号/图标升级
```

- 可访问性引用：MOT-2（演出可关）、TYP-4（结算文本背景）、AUD-2（破境完成三通道）、COL-1（境界图标升级非单靠颜色）。
- 关键：等待 UI 明确标注「可离线，回归自动完成」（U2/P3 保护条款可见化）。

### 3.4 抽卡流（GDD-002 §3.1/§6.2）

```
抽卡入口（图鉴/活动/卡池分段标识）
→ 单抽/十连选择（十连默认可跳过，出货 ≥ 地品保留演出）
→ 演出：出货演出分级（凡/灵 精简 → 玄 常规 → 地/天 全屏紫气 → 帝品 专属演出）
→ 新角色/碎片结算（稀有度着色 + 图标形态双通道 COL-1）
→ 保底提示常驻（「距离保底剩余 X 抽」透明化 G4）
→ 抽卡副产物（源石碎片）计入结算飘字
```

- 可访问性引用：COL-1（稀有度双通道）、MOT-2（演出可关）、TYP-4（结算文本）、AUD-2（出货三通道）。
- 原则：演出分级 = 反馈分层（U5）；高稀有度演出不频繁（保底机制天然控制频率）。

### 3.5 副本扫荡流（GDD-004 §3.1/§6.1）

```
秘境入口 → 副本列表（图标分类色 + 文字双通道）
→ 选择副本（显示：难度档/每日次数/体力消耗/掉落预览）
→ 已 3 星 → 扫荡（一键多连，汇总结算页）
→ 掉落逐个弹出（稀有度着色 §5.4，天/帝品触发紫气）
→ 次数用尽 → 置灰 + 「今日已刷完」文案（不静默失败）
→ 体力不足 → 置灰 + 指向恢复途径
```

- 可访问性引用：COL-1（掉落稀有度双通道）、TYP-4（结算文本背景）、AUD-2（掉落三通道）、INP-1（单设备完成）。
- 原则：扫荡 = 0 操作（U2）；掉落反馈分层（U5：凡/灵精简，天/帝品峰值）。

### 3.6 帝路挑战流（GDD-005 §3/§6）

```
帝路入口 → 帝路地图（北斗七大陆色系，段位地标）
→ 对手列表（5 名推荐：战力/段位/阵容预览，可轻松取胜标记=图标+文字）
→ 选择对手 → 战斗（全自动，服务端结算，可跳过演出）
→ 结算：胜/负 + 积分变化 + 段位进度条 + 连胜计数
→ 晋级演出（全屏紫气 + 地图推进）
→ 防守阵容设置（默认=当前上阵，可手动调整）
```

- 可访问性引用：COL-1（段位/胜负双通道）、MOT-2（演出可关）、TYP-4（结算文本）、AUD-2（胜负三通道）、INP-3（跳过长按/点击）。
- 原则：0 等待异步（U2）；胜负反馈清晰不羞辱（防挫败，GDD-005 §3.4 连胜保护可见化）。

## 4. 反馈与动效规范

### 4.1 演出层级（反馈分层 U5，引用美术圣经 §7 特效三分法）

| 层级 | 触发 | 演出规格 | 引用 |
|---|---|---|---|
| L0 日常 | 收菜、升级、普通掉落 | 数字飘字 + 轻量粒子，≤0.5s | §7.1 仙道/荒古常规 |
| L1 次级 | 小段突破、玄品出货 | 区域性特效 + 图标动画，1–2s | §7.2 Rim Light 短暂点亮 |
| L2 峰值 | 大境界突破、地/天品出货 | 全屏紫气东来 + 角色登场 + 名台词，2–4s | §5.4 帝品/天品演出层级 |
| L3 史诗 | 帝路晋级、帝品出货、赛季结算 | 全屏演出 + 地图推进 + 荣誉墙，3–5s | §7.2 高光时刻信号 |

- **峰值克制**：L2/L3 每 24h 触发次数设计上限（受突破节奏/保底机制天然控制），避免演出疲劳（U5）。
- **可跳过**：所有层级演出可跳过（2x/一键跳过，INP-3）；跳过不吞奖励（结算已由服务端锁定）。

### 4.2 「减少动效」开关覆盖范围（MOT-2）

| 覆盖 | 说明 |
|---|---|
| 强制闪烁/频闪 | 全部关闭，转静态高亮（危险警示、活动提醒） |
| L0–L3 粒子演出 | 转静态高亮 + 文字摘要（如「突破完成」静态横幅） |
| 数字滚动/飞涨 | 转即时静态显示（Tabular 数字） |
| 计时条铭文动效 | 转静态进度条 |
| **豁免（但默认可控）** | 玩家主动开启的演出镜头（如图鉴回放）——默认关，玩家可开 |

- 开关位置：设置 → 显示（一级入口，非隐藏菜单）；开关状态持久化（本地存储）。

### 4.3 反馈三通道（AUD-2 音效替代）

所有关键事件同时触发：视觉（光效/飘字/图标） + 文字（飘字/横幅） + 音效（胜利/失败/掉落/危险）。静音状态无关键信息丢失（accessibility-spec §2.2 验收）。

## 5. 文案基调

### 5.1 风格定位

- **基调**：修仙口语化 + 原著气韵。界面文案不白不文，介于「市井修仙」与「荒古苍凉」之间。
- **例**：
  - 突破确认：「破境如逆天，一步一重劫。确认冲击 XX 境？」
  - 资源不足：「灵石不足，尚缺 X。可往灵石矿脉一探。」
  - 帝路对手：「此人道行与你相当，可堪一战。」
  - 出关结算：「闭关 N 时，灵气充盈，收获颇丰。」

### 5.2 P4 红线（忠于原著）

- 境界名/招式名/人物名**严格采用原著**：轮海/道宫/四极/化龙/仙台；苦海/命泉/神桥/彼岸；心藏…肾藏；招式如「荒古圣体」「斗字诀」等（以原著为准，不发明新境界）。
- 原创内容（支线/活动限定角色）文案须标注「支线/活动」来源，不得与原著主线文案混淆。
- 剧透控制：不出现成仙路终局/狠人因果等后期剧透文案（概念文档 §8.3）。

### 5.3 文案规范

- 字数：按钮 ≤6 字，提示 ≤30 字，弹窗标题 ≤12 字。
- 数字：统一 Tabular 等宽（防跳动，TYP-4 联动）。
- 语态：系统提示用「你」（第二人称直呼），剧情对话用角色口吻。
- 零负面羞辱：失败文案不贬低玩家（「差一线」「再聚灵气」优于「你太弱了」）。

## 6. 逐条引用可访问性规格（14 项核心特性 → UX 落地点）

> 引用 `accessibility-spec §2` 特性；本表为 UX 设计层落地，验收以该规格为准。

| # | 特性 | 分级 | UX 落地点 |
|---|---|---|---|
| 1 | 正文对比度 ≥4.5:1 | Basic/Standard | 全部正文走字体层，墨青半透明底默认；飘字/横幅同规则（§3 各流程） |
| 2 | UI 内对比度 ≥7:1 | Standard | 面板深色底 + 月白字；鎏金仅强调；禁用灰底灰字（§2 导航） |
| 3 | 大字号/图标 ≥3:1 | Basic | 图标 2px 鎏金描边 + 暗底；主按钮/状态图标批量校验（§2 主操作区） |
| 4 | 高对比模式（C1） | Comprehensive | 主题系统一键切换「墨青底+月白/鎏金高亮」；粒子压暗提字（§4.2 开关联动） |
| 5 | 色盲安全（不单靠颜色） | Basic | 稀有度/敌友/段位/状态全部双通道（色值+图标形态/文字），§3 各流程已标注 COL-1 |
| 6 | 色盲滤镜三型预设 | Standard | 设置→显示→色盲滤镜（红/绿/蓝）；切换即时生效（§2 设置入口） |
| 7 | 自定义色相映射（C2） | Comprehensive | 设置页色块编辑器（敌/友/稀有度）；持久化本地（§2 设置入口） |
| 8 | 字号 ≥14px | Basic/Standard | 字体层级按美术圣经 §6.3；布局相对单位（§2 全局） |
| 9 | 动态字号（C4 联动） | Comprehensive | 全局字号变量 12–32px 滑动条；实时生效（§2 设置→显示） |
| 10 | 字幕开关 | Standard | 关键对话/剧情字幕默认开、背景可读；字幕走文本层（§3.1 新手流程） |
| 11 | 音效替代（视觉反馈） | Standard | 胜利/失败/掉落/危险全三通道（§4.3 反馈三通道） |
| 12 | 全字幕+描述性字幕（C3） | Comprehensive | 全部语音含字幕 + 环境音描述（「[龙吼]」）；音频事件清单待输出（见 §8 开放问题） |
| 13 | 输入：单设备/重映射/长按/一键式 | Basic–Comprehensive | 主流程单设备可完成；InputMap 重映射持久化；收取/跳过支持长按；一键式接入自动链路（§3 各流程 INP-1/3） |
| 14 | 动效频闪 ≤3Hz + 减少动效 | Basic/Standard | 「减少动效」开关全局（§4.2），覆盖闪烁/粒子/滚动/计时动效；演出豁免但默认可控 |

> 覆盖说明：本表 14 项为核心特性归并（accessibility-spec 特性矩阵共 19 行，其中「信息不单靠颜色」与「色盲安全」合并为 #5、字号/动态字号合并为 #8–9、字幕/描述性字幕合并为 #10/12、输入四子项合并为 #13）。**以 accessibility-spec §2 为唯一验收依据。**
