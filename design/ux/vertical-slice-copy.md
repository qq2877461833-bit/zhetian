## 1. 按钮文案

| 按钮 | 文案（中文） | 说明 |
|---|---|---|
| 主按钮·出关 | **出关** | 主界面焦点位，收菜入口 |
| 主按钮·闭关 | **闭关** | 关闭/退出动作（= 开始离线计时） |
| 主按钮·突破 | **破境** | 境界突破（UX 规格 §3.3：破境 vs 升星命名防混淆） |

## 2. 出关结算弹窗文案

> 触发：玩家回归，结算离线收益（GDD-001 §3.2.3 / UX 规格 §3.2）。

### 2.1 常规结算（未超上限）

- **弹窗标题**：出关结算
- **正文**：
  「道友闭关 **N** 时 **M** 分，灵气入体，收获颇丰。」
- **收益明细**：
  「灵石 **+X**」「修为积累 **+Y**」
- **进度提示**（若有突破进度）：
  「破境进度已推进，可冲击 **苦海→命泉**。」
- **主按钮**：收下灵气

### 2.2 已达上限提示（离线 > 12h）

- **弹窗标题**：闭关圆满
- **正文**：
  「道友闭关多时，已至今日上限（12 时辰）。灵气收纳完毕，余者消散于天地。」
- **补充**（防止"丢收益"误解）：
  「上限外不再产出，明日早些出关，灵气更盛。」
- **主按钮**：收下灵气

### 2.3 版本更新后结算提示（边界情况，GDD-001 §3.4 #5）

- **正文**（附于结算下方小字）：
  「版本更新后产出速率已调整，本次按最新口径结算。」

## 3. 突破成功文案

> 触发：破境成功（GDD-001 §3.1 / UX 规格 §3.3）。文案随演出层级（UX 规格 §4.1 L1/L2）分级。

### 3.1 小段突破（L1 区域性演出）

- **标题**：破境功成
- **正文**：
  「道基再固一分，**苦海**波澜渐平，灵台愈发明澈。」
- **效果行**：
  「产出速率 +5%」「战力 +X」

### 3.2 大境界突破（L2 全屏紫气演出，轮海→道宫等）

- **标题**：境界大进·道宫
- **正文**：
  「五藏轰鸣，神桥贯通，肉身蜕尽凡尘——道友入 **道宫境** 矣！」
- **效果行**：
  「产出速率大幅提升」「解锁：修炼位 +1」「破境等待已消耗」
- **副文案**（P1 情绪峰值，史诗感）：
  「自此天高海阔，帝路可期。」

### 3.3 大境界等待启动（等待 UI 提示，GDD-001 §6.2.1）

- **正文**：
  「冲击大境界需 **1 时辰**（轮海→道宫）凝神。道友可先行离线，归来即破。」
- **说明**（P3 保护条款可见化）：
  「等待期间离线不中断；可用加速符缩短。」

## 4. 推关结果文案

> 触发：主线关卡结算（GDD-003 §4.3 星级 / UX 规格 §3.1/§3.5）。

### 4.1 胜利

- **标题**：道阻且长，初战告捷
- **正文**（按星级分级）：
  - 3 星：「一气呵成，片甲不留。道友已臻 **三星** 之境！」
  - 2 星：「险胜一筹，尚可再精。此关 **二星**，离圆满只差一线。」
  - 1 星：「步步惊心，终得过关。**一星** 入手，来日再战更从容。」
- **奖励行**：「灵石 +X」「源石 +Y」（首通）/「通关奖励 +X」

### 4.2 失败

- **标题**：此路暂阻
- **正文**（无负面羞辱，UX 规格 §5.3）：
  「道友道行尚差一线，强闯恐损道基。或提升境界，或另择阵容，再试不迟。」
- **提示行**（给路径，不硬卡死，GDD-003 §5.4）：
  「距通过战力尚差约 X，可往「突破」或「养成」提升。」

### 4.3 验证关未通过（绑定突破，GDD-001 §3.3 / GDD-003 §4.2）

- **正文**：
  「此关为破境验证，需 **三星** 方可通关。道友可先打磨阵容，再战此关。」
- **按钮**：返回布阵（次级） / 再战一次（主）

### 4.4 战斗超时（120s 上限，GDD-003 §5.4 #1）

- **正文**：
  「战至力竭，未分胜负。若道友阵容得当，当可速战速决。」

## 6. 文案规范附注

1. **P4 红线**：境界名（苦海/命泉/神桥/彼岸/心藏…）严格采用原著，不发明新词；招式/人物名忠于原著（本切片仅涉及境界，无原创名词）。
2. **无负面羞辱**：失败/受阻文案均为"尚差一线""再试不迟"等建设性语气，绝不贬低玩家。
3. **数字规范**：所有数值用 Tabular 等宽字体；"N 时 M 分"、"X"为占位，由数据表填充。
4. **可访问性**：全部弹窗文本带墨青半透明底；不依赖颜色传达胜负/星级（星级用图标+文字双通道，accessibility-spec §2.4）。
5. **占位标记**：本切片中 `X`/`N`/`+X` 为动态占位，接入数据表后替换；若文案与数据表字段名需对齐，以 `data/tables/*.json` 为准。
