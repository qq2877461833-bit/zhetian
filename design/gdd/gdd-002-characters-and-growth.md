## 1. 系统概述与设计目标

### 1.1 概述

本 GDD 定义《遮天》的核心资产层：**角色**（IP 群像载体）与**养成**（成长路径）。它是 P2"帝路群像"的直接实现系统，同时衔接 GDD-001 的境界模板与多修炼位架构。

- **角色获取**：抽卡 + 剧情赠送双通道，MVP 首发 30 名（原著占比 ≥ 70%）。
- **养成维度**：等级 / 境界（引用 GDD-001）/ 突破升星 / 法宝 / 功法，五维构成"看得见、可规划"的成长树。
- **角色境界架构（本 GDD 核心决策）**：每角色独立境界 + 账号境界上限约束（详见 §3.3）。

### 1.2 设计目标（可验证）

| 目标 | 验收口径 |
|---|---|
| G1 角色池规模 | MVP 首发可收集角色 ≥ 30 名，原著角色占比 ≥ 70%（≥21 名）；首月内免费可得 ≥ 12 名（剧情+活动，非全抽卡） |
| G2 养成深度 | 每角色至少有 2 个可独立规划的养成维度（境界 + 至少一项非境界维度），同一资源在不同角色间存在分配取舍 |
| G3 无唯一最优解 | 任意单一阵容不可通吃所有玩法；至少存在 2 套互相克制的阵容流派（配合概念文档 §9） |
| G4 商业化透明 | 抽卡保底公开、概率公开；付费不直接获得"已养成角色"（只获得新角色 + 资源加速） |

## 2. 设计支柱映射（P1–P4 逐条校验）

| 支柱 | 本系统如何支撑 | 校验锚点 |
|---|---|---|
| **P1 逆天争锋** | 角色境界突破（引用 GDD-001 峰谷）是成长峰值；升星/法宝/功法提供次级峰谷，避免单一系统疲劳 | 多角色独立境界 → P1 锚点 `last_breakthrough_ts` 改为账号级"任意角色最近突破"；48h 无任何角色突破即告警 |
| **P2 帝路群像（核心）** | 角色池 = IP 资产池；原著角色收集 + 图鉴 + 羁绊；多修炼位让收集角色"上场上岗"而非纯收藏 | MVP 30 角色/原著 ≥70%；图鉴完成度是长期目标（Achiever/Collector 双驱动） |
| **P3 片刻亦修仙** | 养成操作轻量：一键突破、一键升级、抽卡演出可跳过；多修炼位管理在单会话内可完成 | 单会话养成主操作 ≤ 3 个；抽卡十连/单抽均支持跳过演出 |
| **P4 忠于遮天** | 角色人设/技能名/境界沿用原著；新增原创角色限支线/活动，不进核心主线 | 人设红线：核心人物命运结局不可改；原创角色标注"支线限定" |

> 支柱漂移自查：任何降低"角色收集回报"或"养成可见度"的设计改动，先过 P2 锚点；任何引入"强制在线养成"的改动，先过 P3。

## 3. 核心机制与数值框架

### 3.1 角色获取

#### 3.1.1 双通道

| 通道 | 说明 | 占比（MVP 30 名） |
|---|---|---|
| **剧情赠送** | 主线关键节点必得：开场送主角叶凡；轮海毕业送剧情绑定角色（如庞博）；道宫毕业再送一名 | ≥ 5 名（固定） |
| **抽卡** | 卡池按稀有度分层；含活动限定角色 | ≤ 22 名（含 3 名限定） |
| **活动/兑换** | 活动商店、图鉴兑换（确保非酋有稳定收集路径） | 3 名 |

> **原创角色投放注记（拍板定案）**：原创角色 4–6 名，全部限支线剧情/活动获取，不进核心主线；人设与原著核心人物不冲突（P4 红线）。

#### 3.1.2 抽卡分层与概率（公开，G4）

> 稀有度引用美术圣经 §5.4 色阶：凡 → 灵 → 玄 → 地 → 天 → 帝品。

| 稀有度 | 概率 | 说明 |
|---|---|---|
| 凡品 | 59.7% | 基础素材/低星角色（舍入误差吸收档，见下方注记） |
| 灵品 | 25% | 常见角色 |
| 玄品 | 10% | 中坚角色 |
| 地品 | 4% | 主力角色（保底锚点） |
| 天品 | 1% | 核心角色 |
| 帝品 | 0.3%（含硬保底） | 原著顶尖（狠人/无始/虚空等），限时概率UP |

> **概率唯一事实来源（V1.1.1 注记）**：六档求和须 = 100.0%。原稿凡品 60% 使求和 100.3%，已由工程线在 `data/tables/gacha.json` 修正为凡品 59.7%（舍入误差吸收进低保素材档，其余五档保持精确值，保底 60/90 不变）。**抽卡概率以 `data/tables/gacha.json` 为数值唯一事实来源**；本表为设计意图参考，任何数值调整走数据表并同步本表。

- **卡池分段（拍板定案）**：按账号境界分段开放——**轮海期**（账号主线境界为轮海）卡池仅开放 凡/灵/玄 三档；**道宫后**开放 地/天 档；**帝品**仅限后续大境界/限时活动（与 GDD-002 §3.3 账号境界上限约束匹配，防止早期抽到顶级角色碾压）。
- **保底公开**：每 60 抽必出 ≥ 地品；每 90 抽必出 ≥ 天品（含帝品概率UP池独立保底）；保底计数跨卡池不重置，UP 池计数在活动结束后继承到常驻池（防"清空进度"争议）。
- **抽卡副产物（衔接 GDD-001）**：每次抽取返还"源石碎片"，集齐可兑换源石（稳定转化，与 §5.1 源石稀缺性不冲突——副产物是"低保兑换"而非"速成"）。

### 3.2 养成维度

| 维度 | 资源消耗（引用 GDD-001 双币） | 效果 | 峰谷定位 |
|---|---|---|---|
| **等级** | 经验书（副本产出）+ 少量灵石 | 基础数值（攻击/生命） | 平滑成长 |
| **境界** | 灵石 + 源石 + 关卡验证（GDD-001 模板） | 速率 R_c、基础数值、技能解锁 | 主峰谷（P1） |
| **突破升星** | 同名角色碎片 / 通用升星材料 | 稀有度不升但星级 × 战力系数、解锁被动 | 次级峰谷 |
| **法宝** | 灵石 + 源石 + 法宝材料（副本） | 装备位加成、套装效果 | 中期规划 |
| **功法** | 功法材料（活动/副本） | 技能强化、流派成型 | 后期策略 |

- **命名防混淆**：GDD-001 的"境界突破"（大境/小段）与角色"突破升星"（星级）在 UI 文案严格区分——前者为"破境"，后者为"升星"。
- **养成克制**：源石是境界与法宝的共用稀缺资源 → 玩家必须在"升境界"与"做法宝"间取舍（G2 资源分配策略）。

### 3.3 角色境界架构（核心决策：每角色独立境界 + 账号上限约束）

**决策：每角色独立境界**（非账号共享）。

- **理由**：
  1. **多修炼位架构自洽**（承接 GDD-001 §3.2）：每个修炼位挂一名角色、独立速率 R_c，R_c 由该角色境界决定——若账号共享境界，则所有修炼位速率相同，多修炼位退化为"纯倍数叠加"，失去"让收集角色差异化成长"的策略意义。
  2. **P2 强化**：独立境界让每名收集角色都可被"单独养成"，角色池越大、可并行养成的路线越多，收集回报直接可见。
  3. **资源分配深度（G2）**：独立境界天然产生"先养谁"的取舍——源石/灵石有限，玩家需按阵容规划分配，形成策略层。
- **代价与对策**：独立境界可能放大账号整体数值（多角色同时强）→ 用"账号境界上限约束"封顶（见下）。

**账号境界上限约束（防通胀关键）**：
- 账号有一条"主线境界进度"（以主角境界为代表），是内容解锁闸门（关卡、地图、修炼位、抽卡池分段）。
- 非主角角色的境界上限 = `账号主线境界 - 1 大境`（例：主角在道宫，其他角色最高到轮海毕业）。
- 效果：保证"核心队伍始终领先 1 大境"，防止"全角色同步拉满"的数值爆炸；同时给玩家"先升主角→解锁上限→再补配角"的清晰规划链。

**公式引用（R_c 直接复用 GDD-001 §3.2.1）**：
```
R_c = R0 × 1.6^big_realm_index(c) × (1 + 0.05 × sub_realm_index(c))
```

### 3.4 边界与边缘情况（≥3 类）

1. **重复角色**：抽到已拥有角色 → 转化为该角色碎片（升星材料）；满星后继续溢出 → 转化为通用碎片（可兑换任意角色碎片），杜绝"抽到没用"。
2. **角色被修炼位占用时突破**：占用中角色可正常消耗资源破境，破境瞬间同步更新修炼位速率（服务器结算，不丢产出）。
3. **账号上限未达**：配角境界已达"账号上限 -1 大境"时，突破按钮显示"需提升主线境界"，一键跳转主线/主角养成，不静默失败。
4. **活动限定角色过期**：限定卡池结束后，限定角色进入"复刻排队"（承诺复刻周期，如 2 赛季内），不进常驻池但保证可获得性，防"绝版焦虑"。
5. **离线期间角色完成破境**：离线时若角色资源满足且无等待（小段）或等待已结束（大境界），破境自动完成并在出关结算页汇总展示。

## 4. 玩家流程与体验节奏

### 4.1 核心闭环

```
收集（抽卡/剧情） → 养成（破境/升级/升星/法宝/功法） → 布阵（上阵 4–6 名） → 验证（主线/帝路/试炼塔） → 奖励（资源/碎片/图鉴） → 回到收集/养成
```

### 4.2 四循环落点

| 节奏层 | 落点（本系统） | 玩家体验 |
|---|---|---|
| 微循环（1–10min） | 收菜（修炼位产出）→ 1 次破境/升级 → 抽卡（如有券） | 即时成长：数字上涨、新角色入手 |
| 中循环（30–120min） | 推主线 → 领剧情角色 → 换阵容 → 刷副本材料 | 目标感：解锁新角色/法宝 |
| 大循环（1–7 天） | 主角破大境 → 解锁账号上限 → 补养配角 → 卡池保底推进 | 成长史诗：阵容成型 |
| 超长循环（月级） | 图鉴完成度、限定角色收集、赛季活动 | 长期留存：收集全图鉴 |

### 4.3 新手指引（衔接 GDD-001 §4.3）

- 第 0–10 分钟：仍是"收菜→破境"单核心动作；**不展示抽卡**。
- 第 10–20 分钟：首次剧情赠送角色（庞博）→ 教"多角色 = 第二个修炼位占用"（若已达轮海毕业）或"角色可上场"。
- 第 20–30 分钟：首次十连（系统赠送券）→ 教抽卡、保底、图鉴。
- **原则**：收集入口在破境闭环稳定后才开启，防止新手期认知过载（概念文档 §9）。

## 5. 经济设计

### 5.1 资源流向（承接 GDD-001 双币）

```
灵石（挂机/关卡） ──→ 等级、境界（破境）、法宝强化
源石（副本/活动/抽卡副产物） ──→ 境界（源石成本）、高稀有度法宝
角色碎片 ──→ 升星（同名/通用碎片）
功法材料 ──→ 功法强化
```

- **源石是"境界 + 法宝"双消耗**：玩家在"整体战力（多角色境界）"与"单体深度（法宝）"之间取舍——这是 G2 资源分配策略的核心张力。
- **抽卡经济**：抽卡券（付费/活动）→ 抽卡 → 角色/碎片 + 源石碎片。付费直接获得"新角色"（角色获取），但不直接获得"角色养成进度"（等级/境界/升星），符合 G4 红线。

### 5.2 商业化红线（承接 GDD-001 §5.3）

- ✅ 可售卖：抽卡券、资源礼包（灵石/源石）、加速道具（大境界等待）、皮肤/称号、图鉴解锁。
- ❌ 禁止：直接售卖"已满级/满星角色"、售卖"角色境界直接提升"、售卖"保底进度重置保护之外的概率改动"。
- 原则：**付费买"角色与时间"，不买"养成结果"**；保底与概率公开，不设"隐藏概率池"。

## 6. UI/UX 要点

### 6.1 卡面与稀有度（引用美术圣经 §5.4）

- 角色卡面稀有度着色、图标形态层级严格引用 §5.4 六档色阶（凡→灵→玄→地→天→帝品），**不另起色阶**。
- 卡面展示：立绘 + 境界（破境等级）+ 星级 + 阵营/职业标识；破境后卡面动态升级（边框流光、背景升级）。
- 图鉴页：按原著/原创分组，未收集角色显示"剪影 + 神秘感"（触发收集欲）。

### 6.2 抽卡演出

- 十连：默认可跳过（P3 友好），完整演出仅在"出货 ≥ 地品"时保留——高稀有度 = 全屏紫气东来（§5.4 帝品/天品演出层级）+ 角色登场 + 名台词。
- 保底提示：抽卡界面常驻"距离保底剩余 X 抽"，透明化（G4）。

### 6.3 养成 UI

- 角色详情页：五维养成入口（等级/破境/升星/法宝/功法）横向排布，缺资源项显示"快速获取"跳转。
- 修炼位管理（承接 GDD-001）：修炼位列表 = 角色选择 + 当前速率 R_c + 破境快捷入口；占用中角色可一键切出（但切出即停止该位产出，需二次确认）。
- 可访问性（对齐美术圣经 §9）：稀有度不单靠颜色（图标形态双通道）；抽卡演出提供"减少动效"开关；角色名/境界文本字号 ≥ 14px。

## 7. 平衡与数值红线

### 7.1 防通胀（衔接 GDD-001 §7.1）

1. 账号境界上限约束（§3.3）：非主角角色 ≤ 主角 -1 大境，防全角色同步爆炸。
2. 源石双消耗（境界 + 法宝）制造分配瓶颈，源石总量仍受副本/活动限量约束。
3. 修炼位 MVP 封顶 3（GDD-001 §3.2.4），角色再多也受修炼位限制总产出。
4. 30 天模拟器验证：全角色养成总消耗 > 30 天总产出（免费+付费极端值），预留余量。

### 7.2 杜绝唯一最优阵容（配合概念文档 §9）

- **职业/属性克制环（拍板定案：原著向命名）**：三类闭环克制——**荒古体质 → 仙道神通 → 兵器流派 → 荒古体质**（体修克术修、术修克器修、器修克体修），任意单一阵容必然被至少一类克制；命名对齐 P4 原著气质（荒古体质=肉身/血脉强者，仙道神通=术法/咒印，兵器流派=法宝/剑器）。
- **流派互补**：同稀有度角色分属不同流派定位（输出/坦克/控制/辅助），阵容 = 定位搭配而非"全放最高稀有度"。
- **羁绊限制（拍板定案：MVP 6–8 组）**：羁绊加成要求"同阵营"或"特定组合"，诱导玩家使用冷门角色组队，而非全堆顶级；具体组合表与加成幅度待 GDD-003 战斗数值对齐。
- **验证**：上线前用模拟器跑"全稀有度最高阵容"胜率，若对任意阵容 >90% 视为主导策略，必须削弱。

### 7.3 P2 失守自查锚点（埋点规格）

- 埋点：`character_acquired`（角色/稀有度/来源）；`collection_completion`（图鉴进度）。
- 告警：首月"图鉴完成度"中位数 < 30%，或"仅靠抽卡获得角色占比" > 60%（剧情/活动赠送不足）→ 判定 P2 失守，补充免费获取渠道。
- 保底兑现：保底触发率与公告概率偏差 > ±0.5% 即告警（数值/随机实现错误）。

## 8. 开放问题与后续系统依赖

### 8.1 开放问题（待拍板）

**已拍板定案（V1.1）**：
- ✅ 职业分类命名：**原著向三角克制**（荒古体质 → 仙道神通 → 兵器流派 → 荒古体质）。
