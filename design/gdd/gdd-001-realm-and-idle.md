## 1. 系统概述与设计目标

### 1.1 概述

本 GDD 覆盖两个互为表里的系统，是《遮天》"逆天改命"循环的地基：

- **境界系统**：玩家从"轮海境"起步，沿原著境界体系（轮海→道宫→四极→化龙→仙台）逐段突破，是长线成长主轴，承载 P1（逆天争锋）与 P4（忠于遮天）。
- **放置收益系统**：多修炼位并行挂机产出（灵石/经验）+ 离线收益 + 修炼位管理，承载 P3（片刻亦修仙）的经济底座；"闭关修炼→出关结算"的母题化叙事包装。多个修炼位各自独立挂一名角色、独立结算，账号级汇总——多角色同时上场放置，强化 P2 帝路群像。

两个系统耦合点：**突破消耗资源（放置产出），突破提升产出效率（放置提速）**，形成"修炼→突破→更高效修炼"的闭合循环。

### 1.2 设计目标（可验证）

| 目标 | 验收口径 |
|---|---|
| G1 突破爽感 | 玩家每 24h 至少经历 1 次"积累→瓶颈→突破"峰谷；48h 无突破即判定 P1 失守（埋点检查） |
| G2 片刻可玩 | 单次会话 1–10 分钟内，收菜+突破+推关三动作可完成且都有回报 |
| G3 回归友好 | 离线 12h 上限内回归，收益不惩罚（效率 ≥ 在线 80%），且回归瞬间有"闭关结算"仪式 |
| G4 防通胀 | 资源产出有边际收益递减，突破成本指数增长，离线收益封顶，杜绝"一天毕业" |

## 2. 设计支柱映射（P1–P4 逐条校验）

| 支柱 | 本系统如何支撑 | 校验锚点 |
|---|---|---|
| **P1 逆天争锋** | 境界突破是唯一"成长峰值"事件；突破消耗"资源+关卡验证"，形成积累→瓶颈→突破的峰谷 | 埋点：`last_breakthrough_ts`；超 48h 触发 P1 失守告警（见 §7.3） |
| **P2 帝路群像** | 境界是角色养成（等级/突破）的上层框架；**多修炼位架构下，玩家同时放置多名角色，收集的角色越多可并行修炼越多，直接激励角色池扩充** | 境界数值模板必须"角色通用"（非主角专属），保证任意角色可套用；修炼位数量与角色池扩张正相关（见 §3.2.4） |
| **P3 片刻亦修仙** | 离线收益+修炼位保证"即开即玩即有获得感"；突破无强制在线时长（不设"必须在线 X 小时"），回归不惩罚 | 离线效率 ≥ 在线 80%；单会话最小闭环 ≤ 10 分钟（见 §4） |
| **P4 忠于遮天** | 境界名称/结构严格采用原著：轮海（苦海→命泉→神桥→彼岸）、道宫（五神藏）、四极、化龙、仙台 | 结构红线：不新增/删改大境界；数值可简化，结构不可改 |

> 支柱漂移自查：任何对"突破时间、离线上限、产出曲线"的改动，先过 P1/P3 锚点；若与"片刻亦修仙"冲突（如引入强制在线收益加成），一律修正。

## 3. 核心机制与数值框架

### 3.1 境界体系结构（对齐 P4）

原著结构（结构红线，不可增删）：
- **轮海境**：苦海 → 命泉 → 神桥 → 彼岸（4 小段）
- **道宫境**：心藏 → 肝藏 → 脾藏 → 肺藏 → 肾藏（5 小段）
- **四极境 / 化龙境 / 仙台境**：MVP 不做具体内容，预留框架（境界 ID 占位），后续版本扩展。

MVP 范围：**轮海（4 段）+ 道宫（5 段）= 9 个小段**，全部落地。四极以降仅保留数据表结构。

每小段突破所需三要素：
1. **资源**：灵石（主资源，量大）+ 源石（稀有，随境界提高权重）
2. **关卡验证**：突破小段需通关指定主线关卡（绑定，见 §3.3）
3. **时间（拍板定案）**：
   - **小段突破：即时完成**，无等待——保持 P3"片刻亦修仙"，单会话内即可连续突破多个小段。
   - **大境界突破（轮海→道宫、道宫→四极…）：设 1–2h 等待时间**，可用加速道具缩短（加速道具见 §5.3）。
   - **P3 保护条款：大境界等待不设强制在线**——等待期间玩家可自由离线，等待计时按服务器时间持续走；回归后若等待已结束，直接领取突破结果并结算离线收益，不因离线而重置或延长等待。等待本质是"时间门槛"而非"在线门槛"。

### 3.2 放置收益数值框架（多修炼位并行模型）

> **拍板定案**：多修炼位并行放置。每个修炼位独立挂一名角色、独立按该角色速率产出；账号级汇总所有修炼位产出。离线收益按各修炼位分别结算后汇总。

#### 3.2.1 单修炼位产出（在线）

主资源 **灵石**（货币，`LING`）——单个修炼位（角色 `c`）的产出速率：

```
R_c = R0 × B^big_realm_index(c) × (1 + 0.05 × sub_realm_index(c))
```

- `R0`：基础速率，MVP 定 `R0 = 10 灵石/秒`（单位：灵/s）
- `B`：境界提升的产出倍率，`B = 1.6`（每突破一个大境界产量乘 1.6）
- `big_realm_index(c)`：角色 c 所在大境界（轮海=0，道宫=1，后续 +1）
- `sub_realm_index(c)`：角色 c 所在小段序号（苦海=0 … 道宫·肾藏=8），每小段 +5%

样例（R0=10 灵/s）：
- 苦海（0,0）：R = 10 灵/s
- 彼岸（0,3）：R = 10×1.15 = 11.5 灵/s
- 肾藏（1,4）：R = 10×1.6×1.2 = 19.2 灵/s

#### 3.2.2 账号级汇总产出（在线）

```
账号在线产出 R_total = Σ R_c   （对所有占用中的修炼位 c 求和）
```

样例：3 修炼位分别挂 苦海(10) + 神桥(11) + 心藏(16.8) → R_total = 37.8 灵/s。

> 设计意图：多修炼位让"收集更多角色 = 更高总产出"，形成 P2 收集→P3 产出 的正向激励；但产出随角色池扩张会加速，须靠 §3.2.4 修炼位解锁节奏 + §7.1 防通胀红线约束总量。

> **源石声明**：次级资源 **源石**（稀有，`YUAN`）不挂机直产，由副本/活动/关卡首通结算（见 §5），放置系统（含多修炼位）均不产出源石——保证双币分层，防止"挂机=毕业"。

#### 3.2.3 离线收益（P3 核心，多修炼位汇总）

```
单修炼位离线收益  L_off(c) = R_c × eff_off × min(Δt_off, CAP_off)
账号离线收益      L_off_total = Σ L_off(c)
```

- `R_c`：结算时该修炼位角色的产出速率（灵/s）
- `eff_off`：离线效率 = **0.8**（80%，不惩罚回归）
- `Δt_off`：离线时长（秒，服务器时间戳）
- `CAP_off`：离线收益封顶时长 = **12h = 43200s**（超出部分不产出，防通胀）

样例：单修炼位苦海 R=10 灵/s，离线 12h → 10 × 0.8 × 43200 = **345,600 灵**；3 修炼位账号 = 各修炼位分别结算后汇总。

> 设计意图：离线 12h 收益 ≈ 在线 9.6h 收益，玩家回归"有获得感"但不至于"离线碾压在线"；封顶让长期挂机者无法无限囤积。多修炼位下各位独立结算、共用同一 12h 封顶口径，避免"多角色叠加超时收益"。

#### 3.2.4 修炼位解锁节奏（定案，配合防通胀）

| 修炼位 | 解锁条件 |
|---|---|
| 第 1 位 | 初始即拥有（新手区开场绑定主角） |
| 第 2 位 | 轮海毕业（突破入道宫）解锁 |
| 第 3 位 | 道宫毕业（突破入四极）解锁 |
| 第 4+ 位 | 扩展层开放项（后续版本按境界/章节/活动扩展，MVP 封顶 3 位） |

> 理由：初始 1 位保证新手上手节奏；前 24h 轮海毕业解锁第 2 位，给予"收集更多角色"的可见回报；道宫毕业解锁第 3 位，配合 P2 角色池扩充。早期总产出受修炼位数量约束，防止"一天毕业"。

#### 3.2.5 边际收益递减（G4）

- **产出**：线性/对数增长（每小段 +5%），增速远低于突破成本指数（见 3.3）。
- **突破成本**：指数增长 `C(i) = C0 × 1.65^i`。
- **修炼位产出叠加**：多修炼位会加速整体产出，但修炼位解锁严格绑定境界进度，且突破成本指数增长仍为主导，整体回本时间仍单调拉长（§7.1 校验）。
- **效果**：玩家越到后期，突破所需时长指数拉长 → 自然放缓节奏，形成"瓶颈期"，防止数值爆炸与一天毕业。

### 3.3 突破成本曲线

第 `i` 个小段突破（i = 0..8）成本：

```
灵石成本  C_ling(i) = C0_ling × 1.65^i
源石成本  C_yuan(i) = C0_yuan × 1.55^floor(i / 4)   （每 4 小段即每大境界升一档）
关卡要求  stage_req(i) = 3 × i + 1                    （第 3i+1 关）
```

- `C0_ling = 50,000 灵`（苦海→命泉首段成本）
- `C0_yuan = 20 源石`（首段）

成本节奏验证（回本时间 = 成本 ÷ 突破前所在小段的在线产出速率，R0=10 灵/s）：
| i | 小段 | 灵石成本 | 突破前速率 R(i-1) | 回本时间（在线） | 累计（理想纯挂机） |
|---|---|---|---|---|---|
| 0 | 苦海→命泉 | 50,000 | 10.0 灵/s | ~1.4h | 1.4h |
| 1 | 命泉→神桥 | 82,500 | 10.0 灵/s | ~2.3h | 3.7h |
| 2 | 神桥→彼岸 | 136,125 | 10.5 灵/s | ~3.6h | 7.3h |
| 3 | 彼岸→心藏 | 224,606 | 11.0 灵/s | ~5.7h | 13.0h（轮海毕业） |
| 4 | 心藏→肝藏 | 370,600 | 11.5 灵/s | ~9.0h | 22.0h |
| 5 | 肝藏→脾藏 | 611,490 | 19.2 灵/s | ~8.8h | 30.8h |
| 6 | 脾藏→肺藏 | 1,008,959 | 20.0 灵/s | ~13.5h | 44.3h |
| 7 | 肺藏→肾藏 | 1,664,782 | 20.8 灵/s | ~21.4h | 65.7h |
| 8 | 肾藏→道宫毕业 | 2,746,890 | 21.6 灵/s | ~34.1h | ~99.8h |

> 节奏判断：
> - 前 24h 内玩家可自然完成 4–5 次突破（i=0–4，理想纯挂机 22h 内完成 5 次）→ **P1 满足**，且前期 1–4h 一次峰值密集，符合"上手即爽"。
> - i=5 回本时间较 i=4 局部回落（9.0h→8.8h）是**设计意图**：进入道宫（大境界跳升，速率 ×1.6）给玩家"新境界新起点"的成就感，随后成本指数增长重新拉长回本，形成"每大境界一个节奏起点"。
> - 后期单段回本拉长至天级（13.5h→34h），形成长线目标。
> - 注意：以上为理想纯挂机值，实际叠加首通/副本/活动奖励会更快；上线前需用模拟器跑 30 天平衡（见 §8）。

### 3.4 边界与边缘情况（≥3 类）

1. **离线超时**：`Δt_off > CAP_off` 时，超出部分不产出，结算界面明确显示"已达今日闭关上限"（附文案），避免玩家误以为丢收益。
2. **资源不足突破**：灵石/源石不足时，突破按钮置灰但显示"还差 X"，点击弹"快速获取"面板（跳转副本/活动），不得静默失败。
3. **关卡验证未过**：突破被关卡卡住时，显示"需通过第 N 关"，一键跳转主线；禁止"付费跳过验证"（违背"不卖成长"红线）。
4. **系统时间回拨/跨时区**：离线时长按服务器时间戳结算（客户端时间不可信），防修改系统时间刷收益；详见 §7 经济红线。
5. **离线期间发生版本更新/数值调整**：结算时若产出速率口径变化，按"结算时最新速率"统一结算，并在结算页提示"版本更新后速率调整"。

## 4. 玩家流程与体验节奏

### 4.1 最小会话闭环（P3 验证）

```
打开游戏 → 出关结算（领取离线收益，演出仪式） → 若资源够：突破 1 次（紫气演出） → 推 1–3 关主线 → 布阵微调（可选） → 闭关（退出）
总时长：5–10 分钟
```

### 4.2 三循环落点

| 节奏层 | 落点（本系统） | 玩家体验 |
|---|---|---|
| 微循环（1–10min） | 收菜+1 次突破+推关 | 即时满足：数字上涨、小段突破演出 |
| 中循环（30–120min） | 突破 2–3 小段、凑齐一波资源副本 | 目标感：向"下一大境界"推进 |
| 大循环（1–7 天） | 轮海毕业→道宫、主线推进解锁新区域 | 成长史诗：境界称号、视觉升级（§6） |
| 超长循环（月级） | 五大境界逐级开放、与帝路竞技联动 | 长期留存：新境界=新数值天花板+新内容 |

### 4.3 新手指引（10 分钟单一核心动作）

- 第 0–3 分钟：九龙拉棺开场演出 → 进入荒古禁地新手区 → **只教一个动作"闭关（放置）→ 出关（领收益）"**。
- 第 3–6 分钟：第一次突破（轮海·苦海→命泉），紫气东来演出（引用美术圣经 §5.4 帝品/天品演出层级），称号加冕。
- 第 6–10 分钟：推第 1 关主线，展示关卡验证与源石首通奖励。
- **原则**：新手 10 分钟内不展示任何其他系统（抽卡/竞技/背包），单核心动作"收菜→突破"，防止认知过载（概念文档 §9）。

## 5. 经济设计

### 5.1 双币分层

| 货币 | 类型 | 来源 | 消耗 | 特性 |
|---|---|---|---|---|
| **灵石**（`LING`） | 软货币/主资源 | 放置产出（在线+离线）、主线关卡、活动 | 突破灵石成本、角色升级、法宝强化 | 海量、日常、可再生 |
| **源石**（`YUAN`） | 稀缺进阶资源 | 关卡首通、副本、活动、抽卡副产物 | 突破源石成本、高稀有度法宝、境界专属道具 | 限量、稀缺、需策略分配 |

设计意图：**灵石管"量"（日常流转），源石管"质"（进阶门槛）**。源石不入放置产出，避免"挂机=毕业"；同时源石不直接商城售卖（见 5.3 红线），保持稀缺性。

### 5.2 流转闭环

```
放置产出灵石 ──→ 突破消耗灵石 → 境界提升 → 产出速率↑ → 更多灵石
     ↑                                                        │
     └──────────── 离线收益（封顶 12h） ←──────────────────────┘
源石：副本/活动首通 → 突破消耗源石 → 境界提升 → 解锁更高副本 → 更多源石
```

### 5.3 商业化红线（"不卖成长本身"）

- ✅ 可售卖：
  - **加速道具（拍板定案）**：针对"大境界突破等待"生效（如"一元加速符"缩短轮海→道宫等待），小段突破即时完成故无加速需求；等待期间可离线，加速道具同样离线生效。
  - 资源礼包（灵石，受境界产出封顶约束）、皮肤/称号、图鉴解锁。
- ❌ 禁止：直接售卖"境界/小段突破"、售卖"关卡通关"、售卖"离线收益倍率永久提升"（可用限时活动，不可永久）。
- 原则：**付费只买"时间与外观"，不买"成长本身"**。境界突破永远是"资源+验证+等待（大境界）"的产物，付费最多缩短等待与积累时长，不跳过验证。

## 6. UI/UX 要点

### 6.1 突破演出（P1 情绪峰值）

- 触发：突破成功瞬间，全屏 `紫气东来` 粒子演出（星紫+鎏金上升态，引用美术圣经 §5.4），角色鎏金描边光（§7.2 Rim Light）短暂点亮。
- 表现层级：小段突破 = 区域性紫气 + 称号更新；大境界突破（轮海→道宫）= 全屏史诗级演出 + 境界图标升级。
- 稀有度视觉：突破成功后，角色卡面/名称稀有度着色按 §5.4 色阶升级（如凡品→灵品），保证"看得见的成长"。

### 6.2 出关结算仪式（P3 回归反馈）

- 回归弹窗"闭关结算"：显示离线时长、产出灵石、突破进度；用卷轴展开动效 + 鎏金数字滚动（引用 §6.1 UI 母题）。
- 关闭按钮高亮"立即领取"，领取时数字飞涨演出；超过 12h 附"已达闭关上限"提示。

### 6.2.1 大境界等待 UI（V1.1 新增）

- 大境界突破启动后：主界面出现"破境中"计时条（铭文刻录动效，引用美术圣经 §6.1 加载语言），显示剩余时间。
- 等待期间按钮提供"加速"入口（指向加速道具/弹购买确认），并明确标注"等待期间可离线，回归后自动完成"（P3 保护条款的可见化）。
- 等待结束回归：弹窗"破境完成"（全屏紫气演出）→ 可直接领取离线收益 + 突破结果，两段结算分离但同屏呈现。

### 6.3 主界面 HUD（收菜入口）

- 顶部灵石/源石栏（稀有度着色，源石用星紫 `#4A3E6E` 标识，与 §5.4 一致）。
- 主按钮"闭关/出关"置于主界面焦点位，一屏即可完成"收菜+突破"两动作。
- 突破按钮在可突破时高亮（鎏金描边 + 轻微脉动），不可突破时置灰并显示缺口。

### 6.4 可访问性（对齐美术圣经 §9 Standard）

- 突破状态不单靠颜色：可突破时按钮同时有"亮边+动效+文字提示"三通道。
- 演出提供"减少动效"开关（关闭后紫气演出转为静态高亮）。
- 数字用等宽字体（Tabular），防跳动。

## 7. 平衡与数值红线

### 7.1 防通胀红线（G4）

1. 离线收益封顶 12h，超出不产出（多修炼位各结算但共用同一封顶口径）。
2. 突破成本指数增长（×1.65/段），产出仅对数增长（+5%/段），回本时间单调拉长。
3. 源石不入放置产出，来源全部为一次性/限量结算（首通/副本/活动），总量可控。
4. **修炼位数量开放节奏（拍板定案，防早期产出爆炸）**：MVP 封顶 3 位，解锁严格绑定境界进度（初始 1 → 轮海毕业 2 → 道宫毕业 3）；第 4+ 位仅作扩展层开放项，不得在 MVP 通过付费提前解锁（防"付费=更多修炼位=更高产出"主导路径）。
5. 版本上线前用模拟器跑 30 天曲线（含多修炼位叠加产出）：任意玩家 30 天内不可达到"全境界毕业"（数值预留余量）。

### 7.2 杜绝主导策略

- 突破资源获取至少两条途径（放置 + 副本/活动），不出现"唯一最优获取线"。
- 无"加速突破"付费捷径 → 无"付费玩家碾压免费玩家"的主导路径。
- 不设"必须在线"加成 → 无"在线党"主导策略，回归公平。

### 7.3 P1 失守自查锚点（埋点规格）

- 埋点：`realm_breakthrough`（事件：角色/境界/时间戳）；`last_breakthrough_ts`（账号级最近突破时间）。
- 告警：任一活跃账号 `now - last_breakthrough_ts > 48h` → 触发告警队列，运营侧检查是否数值卡死（成本过高/关卡验证过难/资源断供）。
- 自动化检查：每日跑批，统计"48h 无突破玩家占比"，目标 < 5%；若 > 5% 视为 P1 失守，立即回滚调整（成本曲线/关卡要求）。
