## 1. 系统概述与设计目标

### 1.1 概述

本 GDD 定义《遮天》的**资源供给层**：副本（稳定产出养成材料与源石）与活动（限时事件化玩法 + 额外供给）。它是 P2 养成资源、P3 短会话、P4 事件化叙事的交汇系统，同时**兑现 GDD-001 §8.1 遗留项"源石掉落密度待副本 GDD 对齐"**。

- **副本类型**：资源副本（灵石/经验书/法宝材料/功法材料）、试炼塔（验证+稀缺资源）、源石秘境（源石主产出，本 GDD 定案）。
- **活动**：限时事件（黑暗动乱、成仙路异动——背景尊重原著，结果可演绎）、周期活动（签到/任务）。
- **体力复用**：副本消耗体力规则完全复用 GDD-003 §3.5（10 体力/次；试炼塔 5/层），不另起体力口径。

### 1.2 设计目标（可验证）

| 目标 | 验收口径 |
|---|---|
| G1 供给稳定 | 玩家在突破节点前可通过副本+首通稳定凑齐所需源石/材料，不出现"资源断供卡死"（源石供给曲线对齐 GDD-001 突破成本） |
| G2 总量可控 | 源石总供给（副本+首通+活动）可被 30 天模拟器验证，防通胀闭环（见 §7.1） |
| G3 短会话 | 单次副本 ≤ 90s（自动），扫荡秒过；每日副本清一轮 ≤ 10 分钟（P3） |
| G4 事件尊重原著 | 活动背景（黑暗动乱/成仙路异动）须尊重原著设定，结果可演绎但背景不可魔改（P4） |

## 2. 设计支柱映射（P1–P4 逐条校验）

| 支柱 | 本系统如何支撑 | 校验锚点 |
|---|---|---|
| **P1 逆天争锋** | 副本供给突破所需资源/材料，与突破成本曲线对齐；试炼塔提供额外成长验证 | 供给曲线 vs 突破成本：任意突破节点前，玩家可经副本+首通凑齐资源（胜率口径见 GDD-003 §7.2） |
| **P2 帝路群像** | 资源副本产出养成材料（经验书/法宝/功法/碎片），支撑多角色差异化养成；活动投放限定角色 | 每日资源供给可支撑 ≥2 角色同步养成（非单角色速成） |
| **P3 片刻亦修仙** | 副本短会话 + 扫荡秒过；每日副本清一轮 ≤10 分钟；活动任务碎片化完成 | 副本单次 ≤90s；扫荡 0 操作；活动单任务 ≤5 分钟 |
| **P4 忠于遮天** | 活动背景引用原著事件（黑暗动乱、成仙路异动）；副本场景引用美术圣经区域矩阵（荒古禁地/秘境） | 活动剧本背景尊重原著因果；场景命名/氛围对齐美术圣经 |

> 支柱漂移自查：任何"副本强制在线""活动强制长在线""资源供给爆炸"改动，先过 P1/P3 锚点；任何偏离原著事件背景的活动剧本，先过 P4。

## 3. 核心机制

### 3.1 副本类型总览

| 副本 | 产出 | 体力 | 每日次数 | 解锁 | 精英档 |
|---|---|---|---|---|---|
| **灵石矿脉** | 灵石（挂机补充外的主动获取） | 10/次 | 3 次 | 主线第 2 章 | 高难高收益（道宫后解锁） |
| **试炼道场** | 经验书（角色等级材料） | 10/次 | 3 次 | 主线第 2 章 | 高难高收益（道宫后解锁） |
| **法宝秘境** | 法宝材料（GDD-002 法宝强化） | 10/次 | 2 次 | 轮海·神桥 | 高难高收益（道宫解锁） |
| **功法洞天** | 功法材料（GDD-002 功法强化） | 10/次 | 2 次 | 轮海·彼岸 | 高难高收益（道宫解锁） |
| **源石秘境（定案）** | 源石（稀缺主产出，见 §3.3） | 10/次 | 2 次 | 轮海·彼岸 | 高难高收益（道宫解锁） |
| **试炼塔** | 源石/碎片/称号/材料混合 | 5/层 | 不限（每日爬层上限） | 主线第 3 章 | — |

- **每日次数**：资源副本每日次数限制（重置于 0 点），配合体力共同控制总供给。
- **扫荡复用**：已通关副本 3 星后开放扫荡（复用 GDD-003 §4.3 规则），扫荡消耗同等体力与次数。
- **精英档（拍板定案）**：每个资源副本设精英档（高难高收益）——解锁条件绑定更高境界/章节（见 §4.1），掉落提升但**每日次数不增加**（仍走普通档的次数池），防资源通胀；精英档 3 星后同样可扫荡。

### 3.2 试炼塔

- **结构**：多层爬塔，每层 1 场战斗（复用 GDD-003 战斗）；层数绑定主线进度解锁（上限 = 主线章节×5）。
- **奖励**：每层首通 = 源石碎片/通用碎片/称号；每 10 层节点宝箱 = 源石 + 抽卡券。
- **每日爬层上限**：每日最多推进 10 层（防一次性速通 + 防挂机刷层）。
- **重置**：不做赛季重置（试炼塔为长期目标），与帝路竞技（GDD-005）区分。

### 3.3 源石产出源头定案（兑现 GDD-001 §8.1 遗留项）

**源石供给结构（MVP 全周期）**：

| 来源 | 类型 | MVP 总量估算 | 说明 |
|---|---|---|---|
| 主线首通 | 一次性 | 87 源石 | 30 关：普通关 2/关 ×21 + 验证关 5/关 ×9 |
| 章节宝箱 | 一次性 | 60 源石 | 6 章 × 10 源石 |
| 源石秘境 | 每日 | ~6 源石/天 | 2 次 × 3 源石（轮海期）/ 2 次 × 5 源石（道宫期） |
| 试炼塔 | 一次性+每日 | ~40 源石 + 每日少量 | 节点宝箱 + 层数奖励 |
| 活动 | 限时 | 每活动 20–40 源石 | 黑暗动乱/成仙路异动等 |

**与突破成本对齐（GDD-001 §3.3）**：
- MVP 全部突破源石需求：`C_yuan(i) = 20 × 1.55^floor(i/4)`，i=0..8 → 轮海 4 段 ×20 + 道宫 5 段 ×31 = **235 源石**。
- 一次性供给（首通 87 + 宝箱 60 + 试炼塔 40）≈ **187 源石** → 缺口 ~48 源石由每日副本+活动补齐。
- 节奏判断（**拍板定案：维持 3 源石/次**）：轮海期源石秘境 42 源石/周，道宫期 5–8 天补齐缺口——与突破节奏（大境界 1–2h 等待 + 资源积累）匹配，**不卡死不速成**。

> 定案口径：**源石主产出 = 源石秘境（每日）+ 一次性首通/宝箱/试炼塔 + 活动**；不进入放置挂机（GDD-001 红线），不直接商城售卖（GDD-001 §5.3）。

### 3.4 体力消耗规则（复用 GDD-003 §3.5）

- 资源副本 10 体力/次；试炼塔 5 体力/层。
- 每日自然恢复 + 领取 + 付费上限均复用 GDD-003 §3.5（上限 120 / 恢复 1 每 5min / 每日免费领 2×30 / 付费 3×60）。
- 副本清一轮体力预算：灵石 3×10 + 经验 3×10 + 法宝 2×10 + 功法 2×10 + 源石 2×10 + 试炼塔 10×5 ≈ **170 体力/日**——在日均可用体力（自然 288 + 领取 60）内，付费体力用于额外刷取（受次数限制约束）。

### 3.5 活动机制

| 活动类型 | 周期 | 内容 | P4 约束 |
|---|---|---|---|
| **事件活动（黑暗动乱）** | 限时（7–14 天） | 黑暗动乱来袭 → 抵御波次副本 + 排行榜 + 活动商店 | 背景尊重原著（黑暗动乱是历史大劫），结果可演绎（玩家抵御的是"余波"），不改变原著结局 |
| **事件活动（成仙路异动）** | 限时 | 成仙路异象 → 探索秘境 + 剧情档案 | 背景尊重原著（成仙路是核心悬念），不揭示终局剧透（概念文档 §8.3 剧透控制） |
| **七日签到** | 周期 | 每日签到 → 资源/抽卡券/碎片 | — |
| **每日任务** | 周期 | 收菜/突破/推关/副本 → 活跃度奖励 | 任务项全部可在 10 分钟内完成（P3） |

- 活动不引入独立货币体系（避免经济分裂）：活动商店统一用源石碎片/活动代币兑换，代币仅活动内消耗、过期清零（防囤积）。

## 4. 副本结构

### 4.1 层级/难度/解锁（绑定主线境界进度）

| 副本 | 难度档 | 解锁条件 | 掉落提升 |
|---|---|---|---|
| 灵石矿脉 | 3 档 + 精英档 | 主线章节推进 / 精英档：道宫后 | 档位越高灵石越多（×1 / ×2 / ×3.5）；精英档 ×4.5 |
| 试炼道场 | 3 档 + 精英档 | 同上 / 精英档：道宫后 | 经验书档位提升；精英档额外掉落 |
| 法宝秘境 | 2 档 + 精英档 | 轮海·神桥 / 道宫；精英档：道宫 | 高阶掉落法宝材料稀有度提升（引用 §5.4 色阶） |
| 功法洞天 | 2 档 + 精英档 | 轮海·彼岸 / 道宫；精英档：道宫 | 同上 |
| 源石秘境 | 2 档 + 精英档 | 轮海·彼岸 / 道宫；精英档：道宫 | 3 源石/次 → 5 源石/次；精英档 7 源石/次 |
| 试炼塔 | 分层（30 层 MVP） | 主线第 3 章起，逐层解锁 | 层数越高奖励越好 |

- **精英档规则（拍板定案）**：高难高收益——解锁绑定更高境界/章节（见上表），掉落提升但**每日次数不增加**（仍消耗普通档次数池），防资源通胀；战力门槛高于普通档最高档，挑战失败不消耗次数（防"被卡死浪费次数"）。

### 4.2 每日挑战上限

- 资源副本：每日次数上限（§3.1 表）；次数用尽后入口置灰显示"今日已刷完"，次日 0 点重置。
- 试炼塔：每日推进上限 10 层。
- 活动副本：活动期内每日次数（如黑暗动乱 5 次/日）。
- 上限口径全局统一：**次数上限 + 体力消耗双闸门**，防无限刷取。

### 4.3 边缘情况（≥3 类）

1. **次数用尽**：每日次数 0 时入口置灰 + "明日再来"文案，不静默失败；不允许付费刷新次数（防"付费=刷资源"）。
2. **体力不足**：复用 GDD-003 §3.5 规则，入口置灰指向恢复途径。
3. **活动过期**：活动结束时未领取的奖励自动邮件补发（24h 内），防"白打"；活动商店代币过期清零前有倒计时提示。
4. **掉落结算中断**：副本结算中断（断线/强退）→ 已通关按正常掉落补发（服务端校验，防吞奖励也防刷）。
5. **难度档切换**：玩家境界提升后副本解锁高阶档，低阶档保留（可手动选择打低档补材料），防"升档后低材料断供"。

### 5.2 体力经济总表（MVP）

| 项 | 值 |
|---|---|
| 体力上限 | 120（建议值，待评审） |

## 6. UI/UX 要点

### 6.1 副本入口与结算（引用美术圣经 §6.1 UI 母题）

- **入口**：主界面"秘境"入口（卷轴展开面板，引用 §6.1 卷轴母题）；副本列表按类型分组，图标分类色引用 §6.2（资源=青铜绿、法力=星紫、仙道=鎏金）。
- **结算**：副本结算页 = 卷轴动效 + 掉落物逐个弹出（稀有度着色引用 §5.4，天品/帝品掉落触发紫气演出）；"再次挑战"与"返回"按钮。
- **扫荡**：一键扫荡 + 扫荡结果汇总页（多次掉落合计，数字等宽字体防跳动）。

### 6.2 试炼塔 UI

- 塔层地图（竖卷轴滑动），已通层打勾、当前层高亮、可扫荡层标记。
- 每 10 层节点宝箱图标（鎏金描边，未解锁灰显）。

### 6.3 活动 UI

- 活动入口（符箓样式，引用 §6.1 符箓母题）+ 活动倒计时（Tabular 数字）。
- 黑暗动乱活动：主界面暗色侵蚀氛围 + 朱砂警示（§9 危险三通道：颜色+形状+动效），"减少动效"开启后静态高亮。

### 6.4 可访问性（对齐美术圣经 §9 Standard）

- 掉落稀有度不单靠颜色（色阶双通道：色值 + 图标形态）。
- 倒计时/次数信息文字 + 数字双呈现。
- 活动提醒不依赖闪烁（提供减少动效开关）。

## 7. 平衡红线

### 7.1 源石总量可控（防通胀闭环）

1. 源石不进入放置挂机（GDD-001 红线），仅副本/首通/试炼塔/活动产出。
2. 每日源石供给（~6–10 源石）× 30 天 ≤ 突破总需求 + 15% 余量（模拟器验证）。
3. 源石秘境次数 2 次/日 + 试炼塔每日上限，双闸门防刷。
4. 活动源石为限时供给，不与每日供给叠加成"爆发期通胀"（活动期总量有预算上限）。

### 7.2 每日收益上限

- 资源副本每日次数上限 + 体力消耗双闸门（§4.2）。
- 活动代币过期清零，防跨活动囤积。
- 收益上限全局口径：**次数 + 体力 + 每日重置**三约束，缺一即视为平衡缺口。

### 7.3 活动不破坏核心经济

- 活动不引入独立货币体系（统一代币且过期清零）。
- 活动奖励源石计入"活动期总量预算"，不超 §5.3 平衡表。
- 活动排行榜仅发外观/称号（不发源石/体力等硬资源），防"排行=资源差距"。

## 8. 开放问题与后续系统依赖
