# 《遮天》可访问性规格（Accessibility Specification）

- 版本：v1.0（Phase 3 技术搭建 · 正式化独立规格）
- 撰写：art-director（林绘澄）
- 上游依据：美术圣经 v0.2 §9 可访问性分级（Basic / Standard / Comprehensive）
- 下游引用方：UX 规格（Phase 4）、QA 测试基线（Phase 5）
- 已拍板决策：**默认目标 Standard + 关键项冲 Comprehensive**（概念评审门控 PASS）
- 关联 GDD 引用点：GDD-001 §6.4 / GDD-003 §6.2 / GDD-004 §6.4 / GDD-005 §6.4（映射见 §4）

---

## 1. 目标声明

> **《遮天》可访问性默认达到 Standard 级；其中 4 项关键特性在 Phase 4/5 冲刺 Comprehensive 级。**

- **为什么 Standard 是基线**：Web 多端 + 移动端兼容是硬前提，可访问性是基础要求而非锦上添花；所有 UI/UX 交付物必须满足本规格 Standard 栏方可进入评审。
- **Comprehensive 关键项**（上线前冲刺，见 §3）：高对比模式、自定义色相映射、全字幕 + 描述性字幕、UI 任意缩放。若资源受限，由 team-lead 与 art-director 按 §3 优先级裁剪，不得静默降级。
- **测试归属**：本规格为 Phase 5 QA 基线的唯一可访问性事实来源；任何条款修订须经 art-director 更新本文档并同步 team-lead。

## 2. 特性矩阵（升级版 · 验收标准 / 实施要点 / 测试方法）

> 分级沿用美术圣经 §9；下表每特性给出三栏可执行细则。UX 规格（design-strategist）须逐条引用。

### 2.1 视觉

| 特性 | 分级 | 验收标准（AC） | 实施要点 | 测试方法 |
|---|---|---|---|---|
| 正文对比度 | Basic/Standard | 正文文本与背景对比度 ≥ 4.5:1 | 字体层优先保证；墨青半透明底 `#1C2A26` @75% 为默认文本背景 | 取 UI 截图，用对比度工具（WebAIM Contrast Checker / 脚本自动采样）逐屏校验 |
| UI 内对比度 | Standard | UI 面板内文字/图标 ≥ 7:1 | 面板深色底 + 月白字为主，鎏金仅作强调；禁用灰底灰字 | 面板专项截图校验；QA 用 7:1 阈值自动脚本 |
| 大字号/图标对比度 | Basic | 大字号（≥24px）与图标 ≥ 3:1 | 图标描边 2px 鎏金 + 暗色底；禁用低对比描边 | 图标资产批量校验描边/底色对比 |
| 高对比模式 | Comprehensive | 一键切换全局高对比（正文 ≥ 7:1 / 图标 ≥ 4.5:1） | 主题系统：高对比模式切换色板为「墨青底 + 月白/鎏金高亮」；粒子与场景画面压暗提字 | 高对比开关下重跑全部对比度用例 |

| 特性 | 分级 | 验收标准（AC） | 实施要点 | 测试方法 |
|---|---|---|---|---|
| 色盲安全（信息不单靠颜色） | Basic（必须） | 无任何「仅靠颜色」传达的信息；敌对/友方/稀有度/状态均有颜色外通道 | 美术圣经 §5.4 稀有度色阶「色值 + 图标形态」双通道；敌对=朱砂+暗紫、友方=鎏金+月白，配文字/图标 | 全局扫描：对关键信息截图去色后仍可辨识；QA 逐系统核对 |
| 色盲滤镜预设 | Standard | 设置内提供三型预设：红盲/绿盲/蓝盲 | Godot 后处理或 UI 层滤镜实现；切换即时生效；预设不改变信息通道（仅色相映射） | 三型滤镜下跑「关键信息辨识」用例集 |
| 自定义色相映射 | Comprehensive | 玩家可手动映射关键色相（敌/友/稀有度） | 设置页色块编辑器；映射持久化本地存储 | 映射后重跑色盲用例；重启会话后映射保留 |

| 特性 | 分级 | 验收标准（AC） | 实施要点 | 测试方法 |
|---|---|---|---|---|
| 字号 | Basic/Standard | 正文 ≥ 14px；支持系统缩放至 200% 且布局重排无截断 | 字体层级按美术圣经 §6.3；布局用相对单位（非固定 px 绝对定位） | 系统缩放 100%/150%/200% 三档全流程走查 |
| 动态字号 | Comprehensive | 设置内 12–32px 滑动条，实时生效 | 全局字号变量接入所有文本节点 | 滑动条遍历边界值，检查溢出/重叠 |

### 2.2 听觉

| 特性 | 分级 | 验收标准（AC） | 实施要点 | 测试方法 |
|---|---|---|---|---|
| 字幕开关 | Standard | 关键对话/剧情提供字幕开关（默认开）；字幕背景半透明可读 | 字幕走文本层（非图片）；背景墨青半透明 | 开/关两态全剧情走查；字幕与语音/文本同步性抽查 |
| 音效替代（视觉反馈） | Standard | 关键音效事件（胜利/失败/掉落/危险）有对应视觉反馈 | 音效触发点同时触发视觉通道（光效/飘字/图标），形成视觉+文字+音效三通道（美术圣经 §9.1） | 静音状态下完整游玩，确认无关键信息丢失 |
| 全字幕 + 描述性字幕 | Comprehensive | 全部语音含字幕；音效/环境（爆炸、龙吼、风声）有描述性字幕 | 字幕管线覆盖所有音频事件；描述性字幕格式统一（如「[龙吼]」） | 全程静音通关测试（音量 0 完成主线） |

### 2.3 操作

| 特性 | 分级 | 验收标准（AC） | 实施要点 | 测试方法 |
|---|---|---|---|---|
| 单一输入完成主流程 | Basic | 仅用鼠标或仅用触屏即可完成主流程（收菜→突破→战斗→结算） | 主循环按钮均在焦点位；无必须键盘+鼠标同时操作 | 单设备输入全流程测试 |
| 按键重映射 | Standard | 键盘操作可重映射；设置持久化 | 输入映射表化（Godot InputMap）；提供恢复默认 | 重映射后功能回归 |
| 长按替代连点 | Standard | 连点操作提供长按等价（如收取/跳过） | 交互组件支持长按触发；长按时长 ≤500ms 免误触 | 长按/连点等价性测试 |
| 自定义灵敏度/一键式 | Comprehensive | 触发阈值可调；提供一键式模式（自动执行多步） | 灵敏度参数化；一键式模式接入自动战斗/跳过链路 | 灵敏度边界值测试 |

### 2.4 认知

| 特性 | 分级 | 验收标准（AC） | 实施要点 | 测试方法 |
|---|---|---|---|---|
| 信息不单靠颜色 | Basic（必须） | 全部状态/阵营/稀有度信息有颜色外通道（文字/图标/形状） | 贯通美术圣经 §9.2 双通道原则；稀有度用 §5.4 色阶双通道 | 去色截图辨识测试（同色盲安全） |
| 动效频闪 ≤ 3Hz | Basic/Standard | 除玩家主动开启的演出镜头外，动效频闪 ≤ 3Hz | 「减少动效」开关（Standard）：关闭后强制闪烁转静态高亮；演出镜头可豁免但须默认可控 | 频闪分析工具/逐帧审查；减少动效开启后全流程走查 |
| 文本背景 | Basic | 所有字幕/悬浮文本带半透明底，任意场景可读 | 文本容器统一墨青半透明底（美术圣经 §9.2） | 明亮场景（雪原/天庭）与暗场景各抽检 |

## 3. 关键项清单（冲 Comprehensive）

> 四项关键特性：**若资源受限，按下列优先级裁剪，不得静默降级**；裁剪决定须经 team-lead 确认并记录。

| # | 关键项 | 优先级 | 归属模块 | 说明 |
|---|---|---|---|---|
| C1 | 高对比模式 | P0（必冲） | 全局主题系统 | 成本低、收益最大；复用主题切换机制 |
| C2 | 自定义色相映射 | P1 | 设置页 | 与三型滤镜共用色相映射引擎，增量成本低 |
| C3 | 全字幕 + 描述性字幕 | P2 | 字幕管线 | 依赖音频事件清单（Phase 4 UX 产出），前置条件明确 |
| C4 | UI 任意缩放 | P2 | 布局系统 | 需布局全面相对化；与动态字号共用变量体系 |
