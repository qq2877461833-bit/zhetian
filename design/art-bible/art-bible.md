## 一、视觉身份总述（一句话审美主张）

> **「荒古苍凉为骨，仙道星辉为魂——以青铜锈色承载万古岁月，以鎏金流彩点亮超脱之路。」**

《遮天》的视觉核心是**二元张力**：一边是荒古禁地、九龙拉棺、青铜巨殿所代表的**苍茫与死亡**（大地、时间、封印），一边是天庭、北斗星域、青帝所代表的**璀璨与超脱**（星辉、云海、飞升）。玩家视觉旅程即在这两极之间穿行——从尘土的厚重走向星空的空灵，凡骨登仙。

审美基调：**东方荒古写实幻想（Grim-Fantasy Xianxia）**——写实足以承载史诗的沉重，幻想足以承载仙道的飘渺；不追求纯粹二次元，也不追求完全写实，落点在于「可信的东方神话质感」。

## 二、风格锚定与参考系

| 《原神》·璃月 | 东方幻想的剪影识别度、场景层次 | 明快的二次元渲染与低龄化表达 |
| 《凡人修仙传》动画 | 修仙题材的角色服饰语言、法术光效方向 | 其对白驱动的动画感 |

| 敦煌壁画/宋青绿山水 | 飞天飘带、金线勾边、留白构图、云气纹 | — |

### 2.2 艺术运动与美术源流
- **宋代青绿山水**：石青石绿的矿彩感 → 场景大色块与雾霭分层。
- **敦煌壁画**：金线勾勒、朱砂点染、飘带流动 → 仙道角色与 UI 描金。
- **青铜器纹样（饕餮纹/云雷纹/夔龙纹）**：荒古建筑、封印、铭文的雕刻语言。
- **水墨留白**：UI 构图与过场叙事的分镜原则——「疏可走马，密不透风」。

### 2.3 风格关键词（供 AI 生成与资产命名统一引用）
`荒古苍凉` `青铜锈蚀` `鎏金星辉` `青绿山水` `水墨留白` `云海雾霭` `仙道飘渺` `史诗列阵` `符文铭刻` `九龙拉棺`

### 2.4 一句话风格禁令（Negative Prompt 统一前缀）
`no neon` `no cyberpunk` `no western fantasy armor` `no cartoon chibi` `no excessive bloom` `no pure-black void`——霓虹、赛博、西式板甲、Q 版、过曝泛光一律禁用。

## 三、核心色调与色彩体系

### 3.1 色板（主/辅/强调三分法）
| 色系 | 角色 | HEX | 色相 | 用途 |
|---|---|---|---|---|
| **主·荒古青铜** | 青铜绿 | `#4A6B5A` | 青灰绿 | 环境基底、荒古建筑、封印 |
| **主·青铜锈棕** | 锈棕 | `#6E5A3A` | 暖棕 | 土地、岩层、木质、旧物 |
| **辅·墨青** | 墨青 | `#1C2A26` | 深青黑 | 阴影、夜空、UI 底 |
| **辅·鎏金** | 鎏金 | `#C9A86A` | 金黄 | 仙道、天庭、神圣光、描边 |
| **辅·月白** | 月白 | `#E8E4D8` | 暖白 | 仙道高光、云气、字体 |
| **辅·星紫** | 星紫 | `#4A3E6E` | 蓝紫 | 星域、法力、北斗、神秘 |
| **强调·朱砂** | 朱砂 | `#A83232` | 血红 | 禁忌、杀伐、狠人、危险标识 |
| **雾霭** | 雾霭灰 | `#8A9288` | 低饱和灰绿 | 大气透视、远景、迷雾 |

### 3.2 色彩心理与叙事用法
- **青铜绿/锈棕（主色，约 60% 画面）**：时间感、封印、苍凉。荒古禁地与凡人境的地面、墙体、岩层。
- **鎏金/月白（辅色，约 25% 画面）**：仙道崇高、飞升希望。天庭、圣地、法术高光、UI 重要元素。
- **星紫（辅色，约 10% 画面）**：星空与法力，北斗星域的专属色；区别于鎏金的「神圣」，星紫是「神秘」。
- **朱砂（强调色，≤5% 画面）**：只在危险/禁忌/剧情高潮出现，占比必须克制，否则失去冲击力。
- **紫气口径规范（跨线统一）**：高稀有度/帝气视觉 = **「鎏金 + 星紫渐变」**（紫金流霞）；**紫气单列为稀有度点缀色**，不作为大面积主色、不独占帝气主视觉。凡「帝气/高稀有度」表达一律先鎏金后星紫，紫气仅作点缀（见 §5.4、§7.1）。

### 3.3 色彩可读性考量
- **亮度层级优先于色相**：所有关键信息（敌方目标、交互物、血条）先靠明度差区分，再靠色相辅助。
- **红绿色盲安全**：禁止「纯红 vs 纯绿」作为唯一区分手段；敌对阵营用「朱砂红 + 暗紫」双通道，友方用「鎏金 + 月白」双通道。
- **文字对比度**：正文 ≥ 4.5:1，大字/图标 ≥ 3:1（见第九节矩阵）。
- **同屏配色上限**：单个场景主色不超过 3 系，避免画面花哨——「青铜 + 鎏金」是默认安全组合。

## 四、角色视觉方向

### 4.1 通用 silhouette 与材质语言
- **剪影识别**：角色 silhouette 必须「三米外可辨」。仙道角色以**飘带/大袖/长发**构成外扩轮廓；荒古敌人以**厚重/狰狞/非对称**构成压迫轮廓。
- **材质阶梯**（按境界/地位递进）：
  1. 凡尘：粗麻、粗布、皮革（低反光、磨砂）
  2. 修士：丝绸、暗纹织锦（微反光）
  3. 仙道/帝者：云锦、金属丝线、鎏金镶边（高反光、流光）
  4. 禁忌（狠人）：材质反光率被刻意压暗，以**哑光 + 局部朱砂**制造危险感。

### 4.2 主角（叶凡）
- **叙事弧线即材质弧线**：起始是荒古山村少年——粗布短褐、草鞋、朴素束发；随境界提升逐步换上云锦仙袍、玉冠。**保留一个贯穿元素**（如贴身的青铜护符）作为身份锚点，保证各阶段剪影可辨识。
- Silhouette：年轻挺拔、长发、修长身段；武器从朴刀/铁尺过渡到长剑/仙器。

### 4.3 重要角色
| 角色 | Silhouette 关键词 | 材质/色彩语言 |
|---|---|---|
| 狠人（禁忌强者） | 修长、面具遮面、长发如瀑、衣袂无风自动 | 哑光暗紫/墨黑 + 朱砂点缀，面具为唯一高光面 |
| 青帝 | 高冠冕旒、大袖垂地、端方如山 | 青莲色（青绿+月白）+ 鎏金，帝者威仪 |
| 天庭/圣地仙官 | 云纹金甲、飘带、对称华贵 | 鎏金 + 月白，甲面抛光高反光 |
| 荒古巨兽/太古生物 | 巨大、岩石/青铜质感、非对称犄角 | 青铜锈棕 + 苔藓青绿，哑光厚重 |

### 4.4 敌对阵营视觉语言
- **黑暗动乱/禁区势力**：暗紫黑雾 + 锈蚀崩解的「堕落金甲」（原本的鎏金被锈蚀侵蚀），表达「仙道被时间腐化」的恐怖。
- **禁令**：敌对不得出现纯黑剪影（可读性差），所有敌人至少保留一个可辨识色相通道（朱砂/星紫/锈棕）。

## 五、场景与环境视觉方向

### 5.1 区域视觉矩阵（意象 → 主色 → 氛围关键词）
| 区域 | 核心意象 | 主色 | 氛围 |
|---|---|---|---|
| 荒古禁地 | 断壁残垣、青铜巨柱、时间凝固 | 青铜绿/锈棕 | 苍凉、封印、雾重 |
| 九龙拉棺 | 九条黑龙/青铜龙 + 星空巨棺 | 星紫 + 墨青 | 史诗、压迫、超自然 |
| 北斗星域 | 漂浮洲陆、星轨、星辉 | 星紫 + 月白 | 空灵、辽阔、神秘 |
| 天庭/圣地（主城） | 金玉殿宇、云海、仙鹤 | 鎏金 + 月白 | 崇高、秩序、光明 |
| 秘境（青帝洞天等） | 青莲、灵泉、云雾 | 青绿 + 月白 | 静谧、生机、超脱 |

#### 5.1.1 北斗七大陆色系矩阵（地图色彩骨架 · 与策划锚点④对齐）
> 概念锚点「北斗星域七大陆 → 地图色彩体系」：以色彩区分地域，作为地图/关卡/活动的主视觉骨架。下表以概念文档明确的五大陆为确定项（色值从既有色板派生，保证一致性）；第六/七大陆名称以策划地图定稿为准，沿用下方「扩展规则」派生，不在此臆造命名。

| 大陆 | 主色 | 色值 | 氛围关键词 | 备注 |
|---|---|---|---|---|
| 东荒 | 青绿 | `#4A6B5A` | 苍莽、古木、荒古圣体故土 | 与主色·青铜绿同源，为默认地图色 |
| 西漠 | 金黄 | `#C9A86A` | 大漠、佛国、炽烈 | 取鎏金降饱和，避免与仙道神圣光混淆 |
| 南岭 | 赤红 | `#A83232` | 妖土、蛮荒、血色 | 取朱砂，禁忌感用于妖族/凶险区 |
| 北原 | 雪白 | `#E8E4D8` | 冰原、苍茫、荒芜 | 取月白加冷灰，需辅以低饱和阴影防过曝 |
| 中州 | 紫金 | `#8B6BC4` | 皇朝、诸子、帝气 | 紫金 = 鎏金+星紫渐变，帝气主视觉 |
| 第六/七陆 | （待定） | — | — | 名称以策划定稿为准 |

- **大陆间视觉隔离原则**：相邻大陆禁止同色相直接接壤，须以雾霭/山脊/星域空间带过渡；单大陆内仍遵循「同屏主色 ≤ 3 系」。
- **扩展规则（供后续大陆/活动地图派生）**：新大陆主色从既有色板选一基础色，再叠加 1 个氛围强调色；禁止引入色板外高饱和新色，违者视为偏离美术圣经。

### 5.2 构图与空间语言
- **垂直构图优先**：修仙题材强调「天-人-地」三层——场景至少保留一层天空叙事（云海/星穹/天光），传达「上有飞升之路」。
- **大气透视分级**：近景（写实材质）→ 中景（雾霭半透）→ 远景（水墨剪影），三层递进压缩远景细节，省资源又出意境。
- **留白原则**：关键战斗/剧情场景保留 1/3 以上负空间（天空/雾海），供粒子特效与 UI 呼吸。

### 5.3 关键意象实现要求
- **九龙拉棺**：必须作为「最强记忆点」级资产制作——九条龙采用青铜+黑金双质感，巨棺表面铭刻云雷纹，背景星轨旋转。此资产允许突破常规面数预算（见第八节）。
- **荒古禁地**：用「雾 + 断裂几何」制造时空错位感，禁区内禁用活物细节，一切以「死寂」为第一优先级。

### 5.4 资源类视觉规格：源石、紫气与稀有度色阶（与策划线锚点对齐）
> 概念锚点「源石与紫气 → 稀有度/境界视觉语言」在本圣经中单列，作为资源类资产（UI 与场景拾取物复用）的统一规格。

- **源石（内蕴神华）**：荒古大地孕育的修行资源。外形为不规则矿晶，外壳哑光青铜/锈棕（承荒古之土），内部「神华」为核心发光体，亮度与稀有度正相关。材质语言：外壳粗糙低反光 + 内核半透明自发光，明暗对比强烈，保证剪影与发光在任意场景可辨。
- **帝气/高稀有度视觉（统一口径）**：最高稀有度与境界突破的专属视觉 = **鎏金 + 星紫渐变**的紫金流霞自东方升腾（挂靠「仙道法术」特效类，禁止与禁忌暗紫混用）；**紫气单列为稀有度点缀色**，用于描边/流光/光点，不作大面积主色。
- **稀有度色阶映射**（UI 图标描边/名称着色复用，含色盲安全通道：色相 + 图标形状层级双通道）：
  | 稀有度 | 色值 | 图标形态特征 |
  |---|---|---|
  | 凡品 | 青铜绿 `#4A6B5A` | 朴素菱形 |
  | 灵品 | 月白 `#E8E4D8` | 菱形 + 单环 |
  | 玄品 | 鎏金 `#C9A86A` | 菱形 + 双环 |
  | 地品 | 星紫 `#4A3E6E` | 菱形 + 三环 + 小光点 |
  | 天品 | 鎏金→星紫渐变 `#C9A86A→#4A3E6E`（紫气 `#8B6BC4` 点缀） | 六边形 + 流光 |
  | 帝品/仙品 | 鎏金 + 朱砂 `#C9A86A/#A83232` 双色（紫气点缀） | 六边形 + 双流光 + 铭文 |
- **一致性约束**：稀有度色阶全局唯一（场景拾取物光效、掉落 UI、背包图标、名称着色统一引用），禁止在任一系统另起色阶，避免「紫色不一定是稀有」的认知漂移。

## 六、UI 视觉方向

### 6.1 界面语言
- **三大母题**：卷轴/符箓/青铜铭文——所有面板以「展开的卷轴」为基本形；按钮与技能以「符箓 + 朱砂印」为基本形；加载与进度以「铭文刻录」为动效语言。
- **构图**：水墨留白，信息区块悬浮于暗色半透明底（墨青 `#1C2A26` @ 75%），不遮挡战斗视野。

### 6.2 图标体系
- 风格：**线性图标 + 鎏金描边**，统一 2px 描边、圆角 2px、同尺寸网格（64/128/256px 三档）。
- 分类色（仅作辅助通道，不单靠颜色）：资源=青铜绿、法力=星紫、仙道=鎏金、危险=朱砂。
- 稀有度着色统一引用 §5.4 色阶映射（含图标形态层级双通道）。

### 6.3 字体层级（Web 字重与嵌入）
| 层级 | 字体 | 字重/尺寸 | 用途 |
|---|---|---|---|
| 标题/Logo | 思源宋体 Noto Serif SC（子集化） | Bold / 28-48px | 章节标题、境界名、Loading |
| 正文 | 思源黑体 Noto Sans SC（子集化） | Regular / 14-18px | 对话、描述、系统文本 |
| 数字 | 等宽数字（Tabular） | — | 数值、计时器（防跳动） |

- **字体体积约束**：仅嵌入用到的字重与字符子集（按剧情文本预生成子集），总字体 ≤ 2MB；移动端优先系统字体回退。

### 6.4 HUD 原则
- 血条/资源条默认**细条 + 数字**双呈现；敌方血条出现在目标头顶，与角色剪影同屏但保持 2px 鎏金描边以区分。

## 七、特效与氛围（VFX / 光影 / 粒子语言）

### 7.1 特效语言三分法（禁止跨类混用）
| 类别 | 色彩/形状 | 粒子形态 | 用途 |
|---|---|---|---|
| 仙道法术 | 鎏金/月白/星紫，符文环、流彩、星辉（紫气仅作点缀，不独占主视觉） | 小型菱形+光点，上升感 | 治疗、飞升、圣光、青帝、帝气 |
| 荒古/封印 | 青铜绿/锈棕，铭文浮现、锈蚀崩解 | 尘粒、碎片、雾团 | 荒古禁地、封印、巨兽 |
| 禁忌/杀伐 | 朱砂/暗紫，黑雾、血光、面具闪光 | 低密度高对比粒子 | 狠人、黑暗动乱、Boss 战 |

### 7.2 光影语言
- 主光：自然天光 + 体积雾（丁达尔效应）塑造「神圣感」；荒古区域用冷青顶光。
- 强调光：角色境界突破/大招时，**鎏金描边光**（Rim Light）短暂点亮——作为全游戏最统一的「高光时刻」信号。
- 阴影：默认柔和阴影；移动端低端档关闭实时阴影，改用烘焙 AO + 假阴影贴花。

### 7.3 粒子与性能原则
- 单场景活跃粒子上限：**≤ 2000 粒子**（桌面）/ **≤ 800 粒子**（移动低端档）。
- 粒子纹理：统一 4-8 张共享粒子图集（星辉、尘粒、雾团、符文、碎片、流光），禁止逐特效独享贴图。
- 粒子生命周期 ≤ 3s，避免残留在屏幕造成视觉噪音与性能损耗。

## 八、技术美术约束（Web 端资源规格）

> **加载预算定稿口径（与工程线 ARCH-ENG-002 §5 分阶段模型对齐）**：阶段0 引擎壳 gzip ≤9MB（硬门禁 12MB，工程侧）→ 阶段1 首屏可玩：引擎壳 + 首屏美术总下载 ≤10MB，其中**美术增量配额 ≤5MB** → 阶段2 长线远程 Bundle 每 ≤3MB。**触发上修**：若阶段0 引擎壳实测 >8MB，阶段1 总口径自动上修为「引擎壳 + 首屏美术 ≤5MB」并同步美术线与策划（预计 ≤14MB）。当前数值**均为待实测目标**（工程线 Phase 4 首日回填），美术资源侧按 ≤5MB 增量配额主动让位；移动端中低端设备可玩为硬前提。

### 8.1 纹理规格
| 资产类别 | 尺寸上限 | 格式 | 备注 |
|---|---|---|---|
| 主角/关键角色 | 2048² | WebP + ASTC/ETC2 | 含 1024² 移动端降级档 |
| 常规 NPC/怪物 | 1024² | 同上 | 远景/小怪 512² |
| 场景大件 | 2048² | 同上 | 每区域 ≤ 8 张 2048 |
| 场景小件/地面 | 512² | 同上 | — |
| UI 图标 | 256²（界面大图 512²） | WebP | UI 图集合计 ≤ 2048²×2 |
| 粒子贴图 | 256² | WebP | 共享图集 4–8 张 |

- 压缩：桌面 DXT/WebP，移动 ASTC 4×4 / ETC2；透明图优先 WebP（无损通道）。
- 纹理通道合并：金属度/粗糙度/AO 合并进 RG 通道，尽量 1–2 张贴图完成一个材质。

### 8.2 网格与图集策略
- 角色面数：主角 **8–15k tris**，NPC 3–8k，怪物 Boss 10–20k（九龙拉棺可放宽至 30k），远景剪影 300–800 tris。
- 场景单体：1–5k tris；地块用 128² 以下密度网格 + 纹理复用。
- 图集策略：按品类分区（角色_/环境_/UI_/特效_），每图集 ≤ 2048²；同图集内资产必须同风格档（避免不同光照烘焙混入）。
- LOD：角色/场景大件至少 2 级 LOD（LOD0 / LOD1 / 剪影），LOD 切换距离按 Web 视距预算（近 10m / 中 30m / 远 60m）。

### 8.3 Shader 与渲染
- **统一 3 套通用 Shader**（禁止逐资产定制）：
  1. 角色/场景 PBR 简化版（GGX + 单层 IBL）
  2. 仙道 Toon/半透明（边缘光 + 流光，用于法术/仙袍）
  3. UI 不透明/渐变
- Shader Variant 总数 ≤ 24；禁实时阴影级联超过 1 层；禁屏幕空间反射（SSR），用反射探针替代。
- 后处理：仅保留 色调映射 + Bloom（低强度）+ 雾效；景深/动态模糊按需开，移动端默认关。

### 8.4 首包与加载（分阶段预算模型 · 引用 ARCH-ENG-002 §5.2）
- **阶段 0 · 引擎壳（工程侧）**：仅引擎 WASM + 引导壳。目标 gzip ≤9MB，硬门禁 12MB；本作 MVP 为 2D 主导，可裁剪 3D/未用模块压更低。此阶段**不占用美术配额**。
- **阶段 1 · 首屏可玩（共享）**：引擎壳 + 首屏美术总下载 ≤10MB；其中**美术增量配额 ≤5MB**（硬门禁 6MB）= 标题场景 + 荒古禁地新手区低模档 + UI 核心 + 字体子集（字体 ≤2MB，见 §6.3）。美术资源侧按此配额反向约束资产数量与档位。
- **阶段 2 · 长线流式（美术+工程）**：荒古禁地后续区域、卡面图鉴、名场面档案、活动内容全部打远程 Bundle，每 ≤3MB；命名 `区域_类型_名称`（如 `huanggu_env_pillar01`）。
- **触发上修**：若阶段 0 引擎壳实测 >8MB，阶段 1 总口径自动上修为「引擎壳 + 首屏美术 ≤5MB」（预计 ≤14MB），工程线同步 art-director 与策划更新本口径。
- **全局资源去重**：共享图集、共享粒子贴图、共享字体子集，避免重复打包；首包与远程 Bundle 之间禁止重复引用同一贴图。

### 8.5 移动端兼容性
- 降级档（低端机）：纹理全降一档（2048→1024）、关闭实时阴影、粒子减半、关闭后处理 Bloom、开启「低画质模式」开关。
- 基准机：2019 年中端安卓（如骁龙 730）+ iOS A13 同等，目标 30fps 稳定。

## 九、可访问性分级（Basic / Standard / Comprehensive）

> UX 规格（design-strategist）必须引用本分级。**《遮天》默认目标：Standard，上线前争取 Comprehensive 关键项。**

### 9.1 特性矩阵
| 特性 | Basic（必须） | Standard（默认目标） | Comprehensive（进阶） |
|---|---|---|---|
| 正文对比度 | ≥ 4.5:1 | ≥ 4.5:1（UI 内 ≥ 7:1） | 高对比模式 ≥ 7:1 全局 |
| 大字号/图标对比度 | ≥ 3:1 | ≥ 3:1 | 高对比模式 ≥ 4.5:1 |
| 色盲安全 | 不单靠颜色传达信息（亮度/形状/文字辅助） | 内置「色盲滤镜」三型预设（红盲/绿盲/蓝盲） | 自定义色相映射 + 材质纹理通道替换 |
| 字号 | 正文 ≥ 14px | 支持系统缩放至 200%（布局重排） | 动态字号 12–32px 滑动条 |
| 文本 | — | 关键对话字幕开关、字幕背景半透明 | 全字幕 + 描述性字幕（音效/环境） |
| UI 缩放 | — | UI 缩放 80%–120% | 任意缩放 + 自定义布局 |
| 输入/操作 | 单一输入方式可完成主流程 | 支持重映射 + 长按替代连点 | 自定义灵敏度、一键式操作模式 |
| 动效 | 不依赖闪烁传达关键信息 | 提供「减少动效」开关（禁用强制闪烁/频闪） | 全动效幅度调节 |
| 反馈通道 | 视觉+文字双通道 | 视觉+文字+音效三通道 | 自定义通道组合（含触觉） |

### 9.2 与视觉身份的直接落地
- 敌对/友方识别：**双通道**（朱砂红+暗紫 = 敌；鎏金+月白 = 友），配 UI 标签文字，色盲安全从美术源头做起，而非事后滤镜。
- 危险警示（禁区/Boss 技）：朱砂红 + 形状（警告环/箭头）+ 闪烁动效三通道并用；「减少动效」开启时闪烁转为静态高亮。
- 文本背景：所有字幕/悬浮文本带墨青半透明底，保证任意场景可读。

### 9.3 评审自查清单（Full 评审用）
- [ ] 关键交互物在色盲模拟（红盲/绿盲/蓝盲）下仍可辨识
- [ ] 无任何「仅靠颜色」传达的信息
- [ ] 最小字号 ≥ 14px，系统缩放 200% 无截断
- [ ] 动效频闪 ≤ 3Hz（除玩家主动开启的演出镜头）
